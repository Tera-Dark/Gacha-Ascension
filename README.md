# 抽卡修仙传 · Gacha Ascension

移动端优先的 **放置 × 增量 × 抽卡** 修仙游戏。核心原则：**战斗获得基础资源，其他养成与构筑通过抽卡获得**；击败地图Boss才能进入下一图，打不过就在当前关刷小怪。修士没有数字等级，轮回永久遗物跨世保留。

> 当前状态（2026-10-20）：**v0.9.4 新手修行引导与境界推进切片已上线试玩，不是完整商业版**。目前前4/24图、炼气初中后圆满及筑基初期可玩。其余地图、境界、法宝和宗门等仍为规划，9分用户体验是目标而非已证实的评分。

## 当前实际可玩

- **地图和境界**：4张地图；各图7段守卫与地图Boss，失败留在当前关。炼气四阶段、筑基初期，修为、悟道与突破丹有实际要求。
- **战斗**：三围、命中、闪避、减伤、功法克制、多波Boss；小怪可选灵石/修为/均衡目标；自动刷怪与有限安全离线结算。
- **九类卡包**：战力、聚财、修为、功法、洞府、灵宠、丹道、第三关开放的「器物秘匣」和筑基期开放的「法器天机」。法器攻防、减益、增益四类效果参与真实战斗，高阶成长仍依赖抽卡。
- **轮回和永久天命**：五阶常规遗物每箱必得，基础攻击/气血/灵石/修为无限叠加；有上限物品满级退出。太古奇珍每箱独立**十万分之一**、鸿蒙异宝每箱独立**百万分之一**，二者无保底、不替代常规遗物、非通关前提。
- **横屏战斗中控台**：桌面/横屏左右分栏、地图滑动抽屉、十槽可穿戴装备（双武器、头冠、帽子、衣服、足履、双饰品、护符、腰带）。筑基起每大境界新增一个独立法器槽，共预留4槽。
- **真正逐击战斗反馈**：不截断战斗日志，每次攻击、闪避、服药、跨波次逐项更新血条并播放受击；守卫/Boss仍采用点击事务结算＋按时序回放。
- **战利品与药品**：怪物概率掉装备箱、药草箱；固定池中开出黄/玄基础装备或2–5份药草，集齐药草炼回春丹、护体散或剑意散。战败有50%概率失去一件随机已穿戴装备；轮回用25因果永久解锁可调阈值自动吃药。

**尚未完成**：全部24图可玩、完整五大境界、法宝和宗门实装、最终美术音效、真实统一战斗时钟、大数体系、云存档及真人留存验证。

## v0.9.5：手动 / 自动冲关真正实时显示与结束时结算

- **根因已修**：v0.9.4 手动小怪、守卫、Boss仍在点击瞬间提交战果，然后压缩回放最长11秒；自动冲关也走相同路径。现删除这种旧回放。
- **统一实时可见层**：手动、守卫、Boss、自动冲关均使用模拟日志原生毫秒时间线逐击更新，血条/治疗/闪避/灵宠/多波敌人的出场同步发生；玩家需要等待真正出手间隔，默认基础攻速约2.45秒，并非点击立即对敌方造成一击。
- **真实结算时点**：新的 `PREPARE_BATTLE` 将战斗种子、开始时间、耗时写入现有Schema 8存档，不发放奖励、不扣药、不判掉装、不推进关卡；`FINISH_BATTLE` 强制检查整场真实时间完成以后才调用旧有`battle()`事务，且只能提交一次。中途抽卡、装备、突破、并发开战都会被保护锁拒绝。
- **刷新与后台恢复**：保存进行中的手动战斗，刷新或切回页面按原来的时间线继续；超过完成时间才执行最终结算，无随机重抽、不重复入账。
- **自动挂机兼容**：自动小怪仍使用既有 `CLAIM_IDLE` 按时批量结算，并继续逐击呈现；自动冲关会先安全停止挂机，创建完整实时守卫/Boss战斗，结束后可恢复刷怪。
- **按钮/反馈**：修正战斗结束后守卫按钮仍被禁用的Bug；战果短暂保留后恢复下一个敌人满血显示。
- **验收**：`tests/v8-true-realtime.test.mjs` 与 Chromium `tests/v8-true-manual-combat-smoke.html` 检验真实逐击先于收益、战斗事务锁、途中刷新和多波Boss/守卫恢复。未修改掉落率、敌我基础属性和原有存档Key。

## v0.9.4：从第一抽到首次轮回的友好流程

- **可跳过的3步引导**：首次进入先看清第一张必得战力卡，之后体验自动刷怪的资源收益，再挑战第一关守卫。完成步骤依据真实存档数据判断，刷新不丢当前教学进度；跳过偏好使用独立本地键，不需要变更Schema8。再次轮回不重复弹新手引导。
- **移动端战斗优先**：手机竖屏将敌人和主要操作放在装备区域前面；初学者暂时收起未用的十槽装备、四槽法器和复杂推演，仍可点击“跳过”恢复全部操作。横屏、桌面既有布局保留。
- **境界与地图绑定**：第一图Boss可开放第二图，但第二图守卫要求至少炼气中期；第三图要求后期、第四图要求圆满。未突破时仍可刷当前地图的小怪获取灵石与修为，修为和悟道足够后再推守卫，保证可达成且不死锁。第四图Boss对应最终筑基。
- **动态目标与抽卡用途**：优先建议首抽、当前地图突破、实际缺少的悟道/灵石/丹药；抽卡页面明确说明每种卡包用途、优先推荐、余额缺口。中期在资金充足时最多建议各体验一次聚财、洞府长期投资，不强制按比例消费，也不改变掉率。
- **防重复点击**：可手动勾选“重复抽卡快捷揭晓”；首抽与高品质机缘始终保留完整动画，奖品照常先结算落盘后显示。取消勾选随时恢复完整仪式。
- **装备与轮回反馈**：背包按钮提示有多少槽位可无损升级；提前提示第四图筑基丹，轮回确认框清楚比较“提前轮回55因果”和“筑基再轮回65因果”，解释40因果遗物箱＋25因果自动服药组合。
- **已验证**：新增真实Chromium首抽→自动刷怪→守卫导引验收，以及5种确定性随机种子的第一世全地图、逐阶段突破、筑基与首轮回测试。**仍非真人留存测试**，也没有扩地图、宗门、完整法宝或服务端存档。

## v0.9.3：针对可玩性的第一轮打磨

- **四组真实共鸣**：流云剑经×青狐（普通攻击+12%）、玄武炼体篇×玄龟（额外12%气血护盾）、御灵同心诀×雷隼（灵宠独立伤害+18%）、九霄破军诀×灵鹿（每第三次爆发伤害额外+25%）。必须同时持有并出战对应功法/灵宠才生效；共鸣没有额外概率、抽卡池、背包实体或存档字段。
- **战前构筑推演**：手动触发，对玩家**已拥有的**功法/灵宠组合采用**同一批16个独立随机种子**计算模拟胜率与存活表现；既不更改存档，也不偷看下一场正式战斗种子。推荐仅代表16次样本，无法保证实战获胜。
- **一键装配**：以单次事务验证两张卡的持有情况并切换，避免功法切换后灵宠没有同步而产生错误结算。已经在自动挂机时先停止挂机和结算收益。
- **修行目标提示**：按当前Boss风险、已装备功法灵宠、境界、修为、悟道和筑基丹动态提示下一步；可跳转到对应卡包，不把“满血量=必胜”误当结论。
- **体验边界**：不会擅自改动卡包概率、法器槽规则、宝箱随机池、死亡掉装、离线限制或存档命名空间。现在仍只有前4张地图可玩。
- **回归测试**：`tests/v8-build-advisor.test.mjs` 覆盖四组共鸣、无所有权时不可生效、原子装配、推演不消耗存档随机数及目标提示。

## v0.9.3 在线战斗时间线热修复

- **自动刷怪在线可视化**：挂机倒计时期间，以实际 seeded 战斗日志的 `timeMs` 显示出手、闪避、扣血、治疗、灵宠攻击；不再等整场结束后才播放逐击日志。
- **单次发奖**：此阶段的逐击画面只是预测演出，最终资源、宝箱、消耗品及战败罚则仍只能由 `CLAIM_IDLE` 一次性提交，刷新不能重复发奖。
- **后台与变装**：重新进入页面或在挂机时调整装备、卡牌，会根据已持续时间恢复当前战斗进度，不重放已发生的攻击；更换构筑后从新的种子与属性生成未结算部分的战斗。
- **自动冲关**：守卫、Boss 回放期间暂停启动新小怪动画，以免画面互相覆盖。
- **持续边界**：手动守卫/Boss挑战仍采用点击结算后按顺序回放；统一的在线战斗事务时钟仍是后续工程目标。
- **验收**：新增逐击时间线单元测试和 Chromium 真正点击「自动刷怪」的中途扣血/完场发奖回归。
