## 1. 游戏定位

### 一句话

**自动探索杀敌 → 获取修为与灵石 → 自主修炼、养成多个独立系统 → 通过功法/洞府/灵宠等分类卡包补足构筑 → 突破境界和更高难度 → 轮回评分兑换因果 → 开天命遗物箱获得永久全局增益 → 下一世再冲更远。**

### 主次关系必须清楚

- **主驱动力**：战力变强、通过当前强敌、突破境界、刷新个人关卡纪录。
- **局内辅助追求**：建洞府提高效率，培养灵宠、功法和法宝形成不同攻略路线。
- **抽卡的定位**：得到稀有系统资产、强化系统上限、创造惊喜与随机差异；**不是提升战力的唯一手段**。
- **局外长期追求**：天命遗物图鉴不断填满，同名无限期跨轮回积累至各自上限；并随着全局增益增加挑战新纪录。
- **不做**：高频手操战斗、复杂走位、人物队伍管理、炼丹材料迷宫、强制刷广告才有重要功能。

核心判据：**把抽卡按钮关掉五分钟，玩家还能否通过杀怪、练功、突破来推进？** 如果不能，说明主循环仍然失败。

## 2. 玩家目标与游玩节奏

| 时间尺度 | 玩家可见目标 | 驱动力 |
|---|---|---|
| 3–15 秒 | 自动斩杀一只敌人，出现伤害和掉落反馈 | 战斗反馈 |
| 30–90 秒 | 主角升级或有灵石强化三围 | 确定成长 |
| 1–3 分钟 | 解锁/装配功法、建第一栋建筑、培养灵宠 | 组合成长 |
| 5–15 分钟 | 战胜一次区段 Boss / 突破一个修炼境界 | 阶段爆发 |
| 单次轮回 | 刷新已挑战主线层数和高难度成绩 | 长目标 |
| 多次轮回 | 收集并叠高天命遗物、提升全局效率、挑战新境域 | 长期收藏 |

节奏为调参目标，并非“玩家待了 N 秒游戏就暗箱补奖励”。

## 3. 关卡：参考《破日开天》的模式，不直接复刻

### 3.1 地图是三层结构

**境域（地图） → 难度（普通/险境/绝境） → 层数（目标百层制）。**

- 境域决定敌人特点、视觉主题、掉落基准、主线解锁；
- 难度决定敌人和收益修正、独立最高层与个人纪录；
- 层数决定本次挑战顺序与阶段守关；
- 第 10/20/30 层（后续 100 层体系则每 10 层）提供精英/Boss 里程碑；
- **额外难度不是前往下一片普通主线境域的强制门槛**。

第一期**不是把百层当成 100 张重复页面**：用关卡数据生成敌人、三围、收益和目标，在可玩纵向切片中先验证 30 层。

### 3.2 具体 P0 与后续范围

| 地图 | 当前原型 | 敌人特色 | 解锁 |
|---|---|---|---|
| 青云山麓·普通 | P0 1–30 层 | 高血、高防、高攻模板轮流出现 | 击败 30 层 → 首次筑基资格与险境开放 |
| 青云山麓·险境 | P0 1–30 层 | 原有怪物专项属性强化 | 完成对应普通难度开启 |
| 赤砂荒岭·普通 | P1 1–30 层 | 高攻击怪、短回合生存挑战 | 练气突破为筑基后开放 |
| 后续沧溟/九霄等 | P2 | 进一步敌人专项克制 | 对应主线里程碑 |

长期逐步扩展每张图的单难度至 100 层；不承诺 P0/ P1 已经完整实现 100 层。青云前 30 层具体敌人表和候选数值在 [关卡 CSV](../data/codex/stages.v0.4.csv)。

### 3.3 冲层 / 扫荡 / 速通纪录

**冲层**：自动连续作战，胜利向前，失败自动停止撞墙并转为可刷的最佳旧层。玩家可以手动重试并查看战败诊断。

**扫荡**：持续重复已经战胜的敌人，仅发常规修为和灵石。按实际胜率、结算时长与奖励计算灵石/分钟、修为/分钟，并提供系统推荐。

**速通纪录**（P1）：重新挑战已通过的整段关卡，记录用时、首次达成里程碑，但**重复速通不持续产生因果**；因果来自轮回按本世最大进度评分。

### 3.4 战斗公式

- 角色三围：攻击 ATK、气血 HP、防御 DEF；
- 自动交替模拟数次交锋，直到一方气血归零或到达回合上限；
- 推荐基础伤害：\`max(1, floor(攻击×100/(100+目标有效防御)))\`；
- 灵宠可独立补刀/护主；功法、法宝产生有来源的战斗修正；丹药提供短时 buff；
- 总战力仅用于 UI **估计**，不能作为胜负判断条件；
- 敌人具有高攻击、高防御、高气血、综合 Boss 等差异，避免玩家永远只追一个总战力数字；
- 首通额外给一次性灵石/修为或免费局内抽卡次数，**绝不掉落系统实体道具**；
- 关卡失败不强制死亡/轮回、不扣局外进度。

## 4. 修士 / 境界：稳定变强的骨架

**由杀怪获得修为、提升主角等级；使用灵石自行投入三条提升路线**：

- **淬锋**：提升攻击，针对高血和高防敌人；
- **锻体**：提升气血，提升面对高爆发怪的生存回合；
- **护脉**：提升防御，减少每回合受伤。

三项成本随购入等级上涨。用户能预览本次强化前后的属性与对当前强敌的估计结果。不支持“只有抽到某张卡才能升等级”。

**大境界**：练气→筑基→金丹→元婴→化神。各自有修为门槛和对应普通主线 Boss 条件；满足两者可主动突破，享受显著基础三围提升，并从锋芒/坚守/聚灵三种道基中选择一个成长倾向。

- 境界等级/地图境域是**两个不同的维度**，允许更高境界回旧图挑战难度。
- 不设置“需要境界突破才能击败获取突破资格的同一 Boss”的逻辑死锁。
- 突破额外属性奖励是否吃遗物加成，由突破当时一次性结算，避免旧存档重复加属性。

## 5. 六个职责清晰的局内系统

| 系统 | 玩家拥有的实体和操作 | 获取方式 | 可成长内容 |
|---|---|---|---|
| 修士/境界 | 等级、突破、三围专项强化 | 探索基础资源 | 不通过卡包直接获取 |
| 背包 | 可消耗道具统一账本 / 全资产只读查看 | 奖励结算器 | 堆叠/消耗，不重复存养成状态 |
| 功法 | 主修/辅修、装备、实际训练 | 功法秘卷包 | 同名解锁训练上限，灵石练功 |
| 洞府 | 3 格设施布局、建造与升级 | 洞府营造包 | 同名解锁升级上限，灵石投资产能 |
| 灵宠 | 拥有物种、培养、升星、1 只出战 | 御兽灵契包 | 灵宠经验 + 同种重复升星 + 灵石投入 |
| 法宝/丹药 | 攻防法宝槽、丹药使用/自动服药 | 法宝珍藏包/丹道宝匣包 | 法宝强化；丹药属于消耗品 |

**背包并非另一条奖励池**：抽卡的功法进入功法系统，抽出的灵宠进入灵宠系统，物品所有权仅有一个权威来源；背包可以聚合展示它们。

### 六系统的互相帮助

- 功法：帮玩家解决战斗短板；
- 灵宠：真实参与结算，影响生存/输出/收益；
- 洞府：牺牲当前灵石，换之后的练功与抽卡预算；
- 法宝：放大功法优势或补足防御缺点；
- 丹药：临时帮助通关/Boss/突破；
- 修士：总是可以依靠杀敌取得基础成长，随机物件不足不会阻断主线。

**每张系统卡初版最多一个跨系统联动**，避免维护时出现无法解释的互相叠增。

## 6. 六类卡包 = 五个当世卡包 + 一个永久天命匣

| 卡包 | 货币 | 抽取内容 | 重复时的成长 | 是否轮回保留 |
|---|---|---|---|---|
| 功法秘卷包 | 灵石 | 功法 | 开启功法的更高可训练上限 | 否 |
| 洞府营造包 | 灵石 | 建筑 | 开启更高可建造等级上限 | 否 |
| 御兽灵契包 | 灵石 | 灵宠 | 同物种升星进度 | 否 |
| 法宝珍藏包 | 灵石 | 法宝 | 进阶上限 | 否 |
| 丹道宝匣包 | 灵石 | 丹药 | 增加消耗品存量 | 否 |
| **天命遗物箱** | **因果** | **永久全局遗物** | **同名被动增益层数+1，满级退池** | **是** |

当世卡包可根据抽取次数提高池等级与高品质出现权重；单抽/十连共享保底累计，但 **不得将天命遗物匣的保底或概率套用到当世卡包**。两者奖励类别和成本不同，独立结算与存档。

### 6.1 天命遗物匣规则总览

- 30 件永久遗物，五档各 6 件；
- **无装备槽、所有已持有遗物全局自动生效**；
- 同名遗物反复获得永久 +1 层，达到上限退出后续奖池；
- 单抽 40 因果、十连 400 因果，基础品质 50%/28%/14%/6.5%/1.5%；
- 每 20 抽内至少一次天阶以上、每 60 抽内至少一次仙阶（可用档毕业则调整提示）；
- 修士基础三围、境界增量、功法数值效果、洞府增产、灵宠强度、探索收益、Boss克制等不同被动词条；
- **绝不直接加成因果收益或永恒遗物开箱速度**；适配永久数值分组与硬上限，不能堆到无限倍率。

详细表与运行规则见 [遗物设计](tianming-relics-v0.4.md) 和 [总图鉴](CODEX.md)。

## 7. 经济循环与“万物靠抽卡”的正确边界

**只有三种基础货币/资源**：
- 修为：战斗获取、自动升级/达成突破条件；当世重置；
- 灵石：战斗获取，用于三向强化、练功、建造、培养、局内分类抽卡；当世重置；
- 因果：轮回评分获得，用于抽局外天命遗物；永久保留。

“万物靠抽卡”指**功法/宠物/建筑/法宝/丹药等稀有系统对象的来源**，不代表每次攻击增长、经验成长都必须开箱。

**核心经济决策**：当前手中 900 灵石，花在角色攻防会马上提高推图能力；拿去建洞府可能在几分钟后回本；抽功法或御兽可获得稀有的针对性方案。

**必须用仿真验证**：
- 第一只高防 Boss 不要求专属卡；
- 洞府投资存在一个有意义但并非必胜的回本窗口；
- 灵石永远有稳定强化出口，不能“已抽满 → 货币无用”；
- 卡包等级/同名重复保持有价值但不出现概率通关墙；
- 经过境界突破，后一境域基础收益有明显跃升。

## 8. 局外轮回与天命遗物

### 8.1 何时轮回

- 玩家自行决定何时轮回，游戏不因卡关强制结束；
- 轮回页面展示当前可得因果、下个里程碑收益，便于判断是否继续；
- 第一次获得有效因果的条件建议是**本世通关青云山麓普通第30层**，更早可重开但不获取因果（需要明确警示）。

### 8.2 评分候选

~~~text
Score =
    12 × 本世普通主线最深总层数
  + 100 × 本世完成境界突破次数
  + 20 × 本世首通精英/区段守关数量（逐个记号且总额封顶）
  + 高难度首通里程碑的有限额外评分

Fate = floor(Score / 10)   // 需要在数值仿真中微调
~~~

例如第一世普通主线第30层 + 第一次筑基 + 2 次计分首通守关 = 50 因果，足够一抽 40 因果的天命箱。轮回分数**不因遗物层数、因果倍率、击杀重复次数而额外增加**。

### 8.3 永久状态

账号保留：因果余额、遗物图鉴与重复层数、两条遗物保底计数、历史成绩与系统永久解锁。重置：修为、灵石、当世所有功法/建筑/宠物/法宝/丹药、卡包升级、当世挑战状态。

旧 v0.3 文档的“三张永久传承卡槽”在本版**不再作为遗物系统规则**；未来若要选择性开局命格，是一个单独的系统，需要再次审稿。

## 9. 玩法解锁与教程

| 首次里程碑 | 解锁内容 | 为什么此时解锁 |
|---|---|---|
| 初始 | 自动探索、主角等级 | 先看到连续击杀 |
| 第3层 | 灵石自主强化 | 第一次有选择的稳定成长 |
| 第6层 | 功法秘卷 / 简化背包 | 学到抽卡是辅助系统资产获取 |
| 第10层 | 洞府营造 | 从只追战力开始考虑经济投资 |
| 第15层 | 灵宠系统 | 战斗小队由主角拓展为主角+一宠 |
| 第30层 | 大境界突破、险境、赤砂主线资格 | 一次大的爽点与后续目标 |
| 第一次有效轮回 | 因果点与天命遗物箱 | 启动局外永久成长 |

法宝和丹药在 P1 新增，避免首局全部系统同时砸向玩家。只出现已经解锁系统的卡包，未解锁的显示有意义的预告信息而非一堆锁按钮。

## 10. 手机竖屏 UX 原则（不是现在的美术定稿）

- 首页中心**一直有自动战斗/当前怪/击杀结算**，战斗是游戏而不是顶部小组件；
- 顶栏：境界、灵石、修为；底栏：仙途 / 修炼 / 养成 / 天命；
- 养成页二级切换功法、洞府、灵宠、法宝、背包；解锁才显示相应入口；
- “我为什么卡关”的原因提示必须包括攻击不足、防护不足或输出回合数；
- 任何“打不过→强化/抽卡/培养”只需 1–2 个跳转并有返回挑战入口；
- 【天命遗物】展示累计生效属性、当前层数、每层增益、保底与剩余收集进度；
- 不用大段静态说明文字代替实际战斗反馈；不把大量机缘卡组成刷屏十连，而淡化击杀过程。

## 11. 广告商业化：明确延后

未来可预留用户主动观看广告的：
- 小额指定局内卡包免费抽卡；
- 短时扫荡灵石/修为加成；
- 本世单次轮回有限因果奖励（必要时独立风控约束）。

**天命最高品质绝不可付费独占**。广告不影响正常自动战斗和修炼。不提供无限广告兑换永久箱子的无上限入口，以免压垮局外进度设计。

具体广告 SDK、备案/资质和发行选择在发布阶段依据当时的 TapTap 官方通道核对；目前不实施真实广告。

## 12. 首版开发顺序与交付验收

| 阶段 | 必须交付 | 游戏性验收 |
|---|---|---|
| M0 · 引擎底座 | 状态、资产登记、关卡配置、战斗纯函数、奖励结算 | 可模拟战斗，资源不重复发 |
| M1 · 探索修炼 | 青云普通30层 + 险境30层、三向强化、境界突破 | 无卡可打前段，卡关可恢复成长 |
| M2 · 两系统 | 功法/洞府/抽卡/背包归属 | 功法影响战斗，洞府有回本价值 |
| M3 · 灵宠 | 宠物出战、经验、星级/培养 | 宠物有真实战报贡献 |
| M4 · 轮回天命 | 评分、因果、遗物池、30遗物、存档迁移 | 第二世有可见成长，保底/退池无漏洞 |
| M5 · 后续 | 法宝、丹药、赤砂主线30层 | 不同策略可通关，选择有取舍 |
| M6 · 打磨与发布 | UI/音效/新手体验/广告适配 | 手机连续试玩与合理留存再进入发布 |

**M4 不应在 M1 的探索和培养依然不好玩时提前开启**，否则局外养成只会掩盖内核的重复性。

## 13. 平衡与自动验证

至少以固定随机种子模拟以下玩家：
1. 只练功、不抽卡；
2. 先投洞府、后养角色；
3. 功法速推；
4. 灵宠辅助成长；
5. 每次有钱就乱抽；
6. 极端低品质运气；
7. 已有高遗物收集进度的老玩家。

同时记录：第一次升级/修炼/卡关/突破耗时，单个区域收益/分钟，灵石用于确定性培养与抽卡的比例，Boss胜率与伤害来源，轮回平均周期，单次因果/分钟，遗物毕业曲线与平均进度差。

**先证明至少三种不同成长策略有适用区间，再扩充几十张新卡。**
