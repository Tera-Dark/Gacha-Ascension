# 《抽卡修仙传》游戏设计文档 v0.2

> 状态：**待讨论 / 尚未批准施工**  
> 项目：Gacha Ascension · TapTap 竖屏轻量小游戏  
> 日期：2026-10-19  
> 目标：用“战力驱动的探索修仙”取代 v0.1 的“抽卡驱动一切”。本文为机制与数值设计提案，不代表现有在线 MVP 已实现。

---

## 0. 一句话定位与设计边界

**一句话**：从凡人出发，持续探索杀敌获取修为和灵石，自主淬炼实力、突破境界，抽取功法/丹药/法宝/洞府补足构筑短板；当成长放缓时主动轮回，抽取永久传承，下一世向更深的仙途推进。

**真正的主循环不是“获得灵石 → 十连 → 更高战力”，而是：**

\`\`\`text
锁定下一关 / 下一重境界
       ↓
自动探索、连续击败怪物
       ↓
掉落修为 + 灵石，积累升级进度
       ↓
角色升级 + 灵石定向强化（稳定变强）
       ↓
遭遇精英/Boss/环境克制，发现短板
       ↓
选择：继续练功、针对性强化、或抽卡寻求稀有突破
       ↓
战胜阻碍 → 解锁新地图/境界 → 收益和战斗体验跃升
       ↓
进入下一轮；成长明显放缓时轮回，获得永久传承
\`\`\`

### 不可偏离的约束

1. **主体验 = 探索杀敌、修炼变强、境界突破**。抽卡是增益、机缘、风格差异，不能承担全部成长责任。
2. 战斗保持**轻量数值对战**，自动结算，不加入走位、技能点击、实时操作；但攻击/气血/防御的差异必须真实影响胜负。
3. 基础掉落只包含**修为与灵石**；功法、丹药、法宝、建筑、特殊机缘等功能性物品**全部通过分类卡包获得**。
4. 单局探索可以不断推进，不强制在固定时长结束；轮回为玩家自选的“以退为进”，不设死亡惩罚。
5. 第一版无需复杂剧情、多角色队伍、大地图探索、联网、装备词条海量洗练或离线数小时生产。
6. 优先手机竖屏，一只手可操作。自动探索时，玩家并非必须持续点击才能获得收益。

### 北极星体验

玩家心里反复出现的念头应当是：**“再打过这关我就能突破，突破后战力会涨一大截；要不先练两级，再抽一次功法试试？”**

不是“灵石又够十连了”。抽卡的惊喜要为追求下一层更强敌人、下一境界服务。

## 1. 为什么 v0.1 不够好玩（针对现有实现）

| 问题 | v0.1 的具体表现 | v0.2 修正方向 |
|---|---|---|
| 战斗没有表现力 | 基本只比较综合战力与敌方阈值 | 由攻击/气血/防御计算少量回合伤害，敌方分类型 |
| 修炼没有控制感 | 修为自动升等级且统一加三围 | 升级提供底盘，灵石投资三条专项强化线 |
| 关卡没有期待 | 无限往上叠层数，Boss 只是更大数值 | 区域主题、守关 Boss、境界关卡、首通里程碑奖励 |
| 抽卡喧宾夺主 | 灵石近乎只能用于卡包；最优策略围绕抽数 | 灵石可用于确定性提升，抽卡负责中长期收益和稀有机制 |
| 资源循环失衡 | 持续刷图能囤积灵石，抽满卡后缺有效消耗 | 修炼成本、抽卡成本、突破需求共同构成消费决策 |
| 构筑同质化 | 很多卡仅提供单项数值，与敌人特点脱节 | 卡片针对战斗瓶颈或提高经济效率，与角色成长互补 |
| 轮回动机不强 | 局外小幅数值增益，下一世大体重复 | 轮回可预览收益，传承带来路线差异，至少一部分解锁新玩法 |
| 过程反馈稀薄 | 主要看战力数字和日志 | 每个小目标可追踪，每次突破有清晰战斗/产出差异 |

**结论**：当前版本的代码可作为技术概念验证，但不是 v0.2 的设计基线；要先替换状态与成长模型，再谈美术。

## 2. 三条互相支撑的成长轴

### 2.1 修为 → 等级 → 境界（不可替代的主轴）

- 击杀任意怪物获得**修为**，自动填充等级经验槽。
- 每次小等级提升，增加基础攻击/气血/防御，并显示「下一层修为所需」。
- **每 10 小等级迎来一个大境界关口**，需要达到修为要求并击败当前区域守关 Boss，才可主动点击「突破」。
- 突破瞬间给予**显著的基础属性跃升**（候选总增幅约 25%–40%，需实测），解锁下一片地图和更高收益。
- 修为达到当前境界上限时，多余修为可以暂存（设合理上限），避免卡 Boss 时刷来的经验白费。

初版 5 个大境界：练气 → 筑基 → 金丹 → 元婴 → 化神。**地图进度与境界互相配合，但不能要求先突破才能打赢同一个用于解锁突破的 Boss**，杜绝进度死锁。

### 2.2 灵石 → 定向强化（玩家自主决定的主轴）

灵石除了抽卡，还能在「修炼」页**确定性强化三条路线**：

| 强化路径 | 提升属性 | 有效应对的敌人 |
|---|---|---|
| 淬锋 | 攻击 | 高气血/高防御敌人，需要更快结束对战 |
| 锻体 | 气血 | 高爆发敌人，需要多扛几次攻击 |
| 护脉 | 防御 | 连续多段伤害敌人，需要降低每次受伤 |

- 每条路线独立等级与价格，价格递增，避免只升级某项毫无成本。
- 重视成长的**可预期性**：强化前显示「升级后属性变化、预计胜率/预计交锋回合变化」。
- 允许花少量灵石进行**本世强化点重分配**，不能因为早期不懂系统而软锁死。
- 灵石的核心选择是：**马上强化保底推图，还是赌一个能改变局势的卡包？**

### 2.3 抽卡 → 功能稀缺性、加速、构筑风格（辅轴）

抽卡提供那些无法用灵石直接购买的特色物品：功法、法宝、丹药与建筑。抽卡**可以产生惊喜，但不应是基本升级的唯一门票**。

- 功法：战斗专项乘区、小范围克制与流派加成。
- 法宝：战斗属性取舍，例如单体爆发/耐久/破甲。
- 丹药：本世持续药效或修为加速，减少操作负担，不做繁琐服药库存。
- 建筑：提高灵石/修为获取效率，构成经济投资。
- 同名卡重复抽到可升级；有阶位、卡包等级和概率递进；卡组需要有限槽位。
- **普通的连续升级，应比抽到普通黄阶卡更有价值；高阶卡或联动成型，应制造足够明显的惊喜。**

### 成长贡献目标（体验方向，非硬编码）

每一世中段，主角实际能感受到的实力提升大致来自：

- 等级/境界：25%–35%；
- 灵石自主强化：40%–50%；
- 卡牌与流派联动：20%–30%。

这是设计归因目标，而不是把数值强行按固定比例相加。即使运气很差，只靠练功也应该能完成前一区域或前两区的基本推进；好卡让玩家冲得更深、走得更快。

## 3. 地图与探索：给战力增长一个可见目标

### 3.1 地图骨架

首版预期 **5 张主题地图 × 每图 10 关 = 50 关**，每张地图最后一关为守关 Boss：

| 地图 | 当前境界 | 主要特点 | 守关体验 |
|---|---|---|---|
| 青云山麓（1–10） | 练气 | 教玩家练功、刷图和首次卡关 | 蛮力妖王：气血高 |
| 赤砂荒岭（11–20） | 筑基 | 物理输出型敌人偏多 | 赤砂炎蟒：攻击高 |
| 沧溟古泽（21–30） | 金丹 | 高防御怪较多 | 玄甲老龟：防御高 |
| 九霄雷域（31–40） | 元婴 | 一部分敌人偏爆发 | 紫霄雷兽：先手压迫 |
| 太虚天门（41–50） | 化神 | 综合属性考验 | 登仙守门者：混合属性 |

前期先实装前 **3 张地图（30 关）**，后两张作为数据结构预留，不应为了凑 50 关重复怪物数值。

### 3.2 自动探索行为

1. 选择「自动探索」后，对当前目标关不断挑战。
2. 战胜普通敌人推进下一关；遇到精英或 Boss 同样自动挑战，Boss 战给出更明显反馈。
3. **卡关后自动转为刷当前已经解锁的收益最优旧关**，不反复空转撞墙。界面始终保留「挑战当前关」按钮。
4. 已通关地图可以自主扫荡。可选择「均衡历练」「求财（偏灵石）」「悟道（偏修为）」三种**掉落比例配置**，没有新货币。
5. 显示当前最接近的目标，例如：「再击败 2 层到守关妖王」「攻击提高约 8% 后可能通关」「距离筑基还差 1 次突破」。

特别说明：**旧关不会掉功法、法宝、建筑或丹药**。基础探索获取修为和灵石；卡牌只能由抽卡产生。

### 3.3 数值战斗，不能只是单一战力判定

保留自动数值战斗，但至少用 3 属性真实计算双方输出与生存：

- **攻击**：影响造成的伤害。
- **气血**：影响能撑过多少次敌方攻击。
- **防御**：降低受伤效率，采用有递减收益的公式，防止无限堆防御无敌。
- 综合战力只用于显示/推荐，**不能直接作为胜负条件**。
- 每场结算模拟 2–10 次交锋；不需要实时技能系统，只播放简洁数值、双方血条、胜负结果。提供「快速战斗」。
- 失败不掉资源、不触发轮回，自动返回收益最优旧关。击败 Boss 有大幅突破提示。
- 若攻击无法战胜当前敌人的防御，应推荐增加攻击；若自己先被击倒，应推荐提高气血/防御。
- 设计上确保任何非 Boss 关都能靠稳定修炼解决，随机抽卡不是硬门槛。

**候选公式（待模拟校准）**：

\`\`\`text
基础伤害 = max(1, floor(攻击 × 100 / (100 + 对手防御)))
暴击/功法/法宝对伤害进行少量修正
两方交替攻击，任一方 HP <= 0 即判胜负
综合战力 = 角色战斗力的估计值，只用于 UI，不用于判胜
\`\`\`

这种公式能使高防敌人需要更久击杀，高攻击敌人会压缩存活回合，从而让投资方向有意义。首版不要大量元素反应、技能冷却、速度条或复杂状态机。

### 3.4 地图奖励

- 普通关：修为 + 灵石。
- 首次通过关卡：给一次性额外基础资源，增强「向前探索」价值。
- 精英关：修为/灵石更高，奖励仍是基础资源。
- Boss 首通：大笔灵石/修为 + **1 次指定卡包免费单抽机会**（注意这只是抽卡机会，不直接产出额外物品）。
- 首次通过整个区域：解锁新地图 + 境界突破资格 + 图鉴记录。

鼓励挑战新层，不鼓励长期刷第 1 层。首通奖励不计入无限刷图收益。

## 4. 境界突破：一定要有让玩家期待的爆发时刻

突破流程：

\`\`\`text
境界修为达到门槛 → 挑战本区 Boss → 取得突破资格
→ 点击「渡劫突破」 → 播放短动画和属性跃升
→ 三选一「本世道基倾向」 → 打开下一张地图
\`\`\`

**道基选择并不是新的物品掉落**，属于修行时选取方向：

- **锋芒道基**：攻击成长更快，适合速推。
- **磐石道基**：气血/防御成长更快，适合稳扎稳打。
- **聚灵道基**：修为或灵石获取更快，适合长期养成。

后续境界继续提供一次倾向强化，玩家可以偏科，也可以混搭。可考虑每世只允许重置一次道基选择，保证局内构筑有后果而非永久犯错。

真正的爽感不是「数字 +10」，而是玩家刚卡住的 Boss 被打过，紧接着突破，切换新地图、刷怪收益暴涨，后面几层快速碾压。

## 5. 经济系统：保证每一次击杀都有用途

### 5.1 只使用三种货币/进度

| 名称 | 获取方式 | 消耗方式/功能 | 是否轮回保留 |
|---|---|---|---|
| 修为 | 探索击杀 | 小等级升级，境界修为门槛 | 否 |
| 灵石 | 探索击杀与卡牌增产 | 淬锋、锻体、护脉；抽取卡包；突破消耗 | 否 |
| 因果 | 根据轮回阶段性成绩结算 | 局外传承抽卡 | 是 |

不加入丹砂、妖丹、木材、矿石等第二层材料，避免资源全靠抽卡导致玩家被迫管理一堆没有意义的库存。

### 5.2 三个消费场景有明确的强弱变化

| 所处阶段 | 通常更值得做什么 | 玩家为什么做 |
|---|---|---|
| 初期，基础属性低 | 少量强化攻击/气血 | 直接过关，立刻得到回报 |
| 中期，培养成本开始明显上涨 | 抽适配卡包，或建建筑 | 用稀有功能与效率增益突破收益递减 |
| 临近 Boss | 根据敌人属性定向强化 / 配装 | 针对短板过关，而非无脑追求战力数字 |
| 明显卡关且下次升级成本很高 | 继续优化经济，或选择轮回 | 玩家选择短期推进还是长期提升 |

### 5.3 动态收益与消耗约束

候选关系式（**参数占位，不是实装承诺**）：

\`\`\`text
敌人强度：随关卡持续增长，Boss 额外倍率
灵石掉落：关卡基础掉落 × 地图收益 × 卡牌收益加成
修为掉落：关卡基础修为 × 地图收益 × 卡牌收益加成
强化价格：基础费用 × 1.17^(该强化路线已购买级数)
单抽价格：一笔固定灵石，十连 = 10 × 单抽
\`\`\`

数值设计的重点不是具体的 1.17，而是以下三个**可测量关系**：

1. 玩家第一次卡关后，通常刷 20–60 秒就能得到**一次可感知的稳定强化**。
2. 玩家每 1–3 分钟可以选择抽一次卡（可能更频繁，但不能靠刷卡占满主要操作）。
3. 每 5–8 分钟左右有一次明显的大目标反馈，例如守关 Boss/境界突破（首次修炼相对慢、后续轮回更快）。

**关键约束：不得出现“抽满普通卡后灵石十万以上却没有有效支出”**；强化价格应作为长线稳定消耗，但不能增长到数分钟都买不起一小点属性。

## 6. 抽卡系统 v0.2：是点缀，但必须足够有趣

### 6.1 仍然保留四类卡包

| 卡包 | 主要作用 | 典型效果 | 对应玩家需求 |
|---|---|---|---|
| 功法包 | 战斗风格、修为效率 | 进攻倍率、高防针对、Boss 增伤 | 卡在强敌前 |
| 法宝包 | 功防取舍、稀有克制 | 破甲、耐久、精英专精 | 特化战力短板 |
| 丹药包 | 短中期修行加速 | 本世持续服用效果、提高修为获取 | 想尽快突破 |
| 建筑包 | 长线收益 | 灵石加成、修为加成、建筑组合 | 想投资长期产出 |

卡包要有**面向任务的用途**，而不是四个外观不同但都给“+5% 战力”的数值池。

### 6.2 五阶品质，重复升级，升级卡包概率

沿用黄、玄、地、天、仙五档。每个卡包分别积累抽取经验并升级；品质从概率池中获得：

- 阶位影响增益强度、成长幅度，以及机制的特殊性；**不能只有倍率差异**。
- 相同卡片重复抽取自动叠加卡牌等级，卡牌上限明确；满级重复卡转换为少量灵石，避免完全作废。
- 卡包达到指定抽数可提升等级，提高高阶品质出现权重，明确概率公示。
- 单抽与十连**累计同一套保底/卡包经验**，不会强迫玩家攒到十连才有合理期望。
- 建议原型先试：每 10 抽至少年中一张地阶及以上、每 40 抽至少一张天阶及以上（均按**每卡包累计**），并通过模拟验证免费玩家的实际抽卡数量；**保底不要求抽够 40 次才能推第一张图**。
- 抽卡“偏好”：允许玩家自主选择卡包，配合当前敌人寻找解法；不加入新手阶段的海量卡池。

### 6.3 有限装备栏，且主动装配不折腾

MVP 目标：功法 2 槽、法宝 2 槽、丹药持续效果 2 槽、建筑 3 槽，共 9 槽。具体上限随实测调整。

- 新卡有空位自动装配。
- 槽满时不按稀有度**强制替换**；系统对比当前卡，给出「预计战斗/产出变化」的推荐，玩家一键替换。
- 允许玩家选择“推荐战斗装配 / 推荐灵石收益装配”快速切换；避免手动整理 40 张卡。
- 少量卡片间拥有**明确但低复杂度的联动**，例如：
  - 青锋剑 + 御剑真解：攻击收益显著提升；
  - 雷引心经 + 五雷天印：对 Boss 增伤；
  - 灵田 + 炼丹坊：探索灵石收益额外增加。
- 特定低阶卡可以作为高阶组合的关键，不该被自动丢弃。

### 6.4 设计样卡（以机制区别于平铺加数值）

| 卡 | 卡包 / 示例阶位 | 效果方向 |
|---|---|---|
| 御剑真解 | 功法·地 | 攻击强化；携带剑系法宝再获得额外攻击 |
| 破甲心经 | 功法·玄 | 对高防敌人伤害效率更高 |
| 金刚护体 | 功法·玄 | 降低高攻击敌人带来的压力 |
| 玄甲盾 | 法宝·地 | 气血 + 防御，偏耐久 |
| 斩妖令 | 法宝·天 | 对精英/Boss 特别有效 |
| 悟道丹 | 丹药·玄 | 修为收益加快 |
| 洗髓丹 | 丹药·地 | 当世持续提高基础属性成长 |
| 山间灵田 | 建筑·黄 | 灵石收益加成 |
| 聚灵秘阵 | 建筑·地 | 修为收益加成；与其他建筑联动 |

**不做**：抽出卡片之后还要手动采集丹药材料、点击炼丹倒计时、制造装备部件。道具卡牌抽到后应当直达功能。

## 7. 第一世的前十分钟：给“下一步想干什么”安排节奏

下面是**体验目标脚本**，不是强制按秒触发的奖励。不能通过时间到点自动赠送资源伪造进度：

| 玩家时间 | 体验与行为 | 设计要传达的念头 |
|---|---|---|
| 0:00–0:45 | 凡人出发，连续击败数只小怪，首次升级；看见下一关和 Boss 预告 | “我很弱，但一直在变强。” |
| 0:45–2:00 | 第一次遭遇明显增压的敌人，灵石足够强化攻击或气血 | “我可以自己决定练哪项。” |
| 2:00–3:30 | 稳定速推，抽到第一张真正有感知的功法/建筑卡 | “这张机缘正好补我的短板。” |
| 3:30–5:30 | 首次遇到精英/小瓶颈，选择刷资源还是偏向抽卡 | “再练一点或试试卡包就有机会过。” |
| 5:30–8:00 | 战胜第一只大 Boss，修为达标后突破筑基，进入新区域 | “突破是整个游戏的大爽点。” |
| 8:00–10:00 | 新地图奖励明显增长，先前吃力的敌人被碾压，开始第二轮投资 | “下一境界的目标已经能看见。” |

各时段都是**调参的目标范围**，不是新增一个倒计时。极端好运或熟练玩家可以更快到达。

### 玩家始终看得见的三层目标

- **几秒钟**：击败眼前敌人，获得修为和灵石。
- **几十秒至数分钟**：升一个小等级、强化一次属性、打过精英或抽到想要的卡。
- **数分钟至十几分钟**：击杀守关 Boss，突破一个境界，解锁下一片地图。

如果 UI 只能显示战力数字和抽卡按钮，设计就仍然失败。

## 8. 轮回与局外成长：把“重开”做成主动期待

### 8.1 什么时候轮回

- 任意时刻可以查看**现在轮回可得因果**与“再过一关/再破一境”的额外收益预期。
- 前期有最低有效结算条件，例如首次击败青云山 Boss；此前可重开，但不奖励因果，防止秒刷。
- 当本世的目标成本过高，轮回提升局外传承便可能更划算；**不设置强制死亡**。
- 轮回后前期推图会因传承加速，玩家应在第 2～3 世明显感受到“上一世难打的怪，现在轻松了”。

### 8.2 评分来源（不奖励无脑刷同一低级怪）

评分基于**最高地图深度、最高境界、Boss 首通里程碑、有限构筑挑战**。击杀总量、累计消耗灵石、重复农怪**不计分或有严格上限**。

参考公式：

\`\`\`text
轮回评分 = 10 × 最高层数 + 80 × 达成大境界次数 + 30 × 已击败的本世守关 Boss + 有上限的首次挑战奖励
因果 = floor(8 + 1.3 × sqrt(轮回评分))
\`\`\`

公式属于候选：重点是**每跨过一段里程碑都比继续刷旧图更赚**，但轮回两分钟一次的刷分效率也要受到约束。最终需要数值模拟后再确定。

### 8.3 局外抽卡：传承不是纯粹的永久属性堆叠

轮回获得因果，用因果抽取**永久传承**，同名可升级。玩家每世进入时带入限定数量的传承（初版例如 3 槽），使传承有取舍。

传承的例子：

- **先天剑骨**：开局攻击成长更快。
- **灵石世家**：开局资源更多，适合速推。
- **聚灵天命**：修为获取倍率更高，适合越级练功。
- **法缘深厚**：每世第一次功法包抽取消耗降低。
- **洞府遗脉**：建筑类卡的产出效果略强。
- **不屈道心**：首次打不过 Boss 时，可以少量降低重复挑战的资源准备成本（具体机制待测）。

推荐局外传承**初期取得要容易、后期提升变慢**；玩家不能因为没抽到某张传承而无法正常推进。第一世达到首个大境界后，应足以进行至少一次有意义的局外抽卡。

## 9. 控制游戏膨胀的 MVP v0.2 范围

### P0 — 先做出确实有内驱力的核心样机

1. 真实三围回合伤害结算（仍然是轻量数值对碰）。
2. 怪物三种基础属性模板：均衡、高攻击、高防御/高气血。
3. 自动推进、卡关后收益最优扫荡、手动重试。
4. 修为等级、灵石三路线自主强化、成本曲线。
5. 前 3 张地图，至少 3 只机制清楚的 Boss。
6. 境界关口与明显突破奖励，突破后下一图收益显著变化。
7. 三层目标 UI：眼前敌人/下次强化/下次突破。
8. 地图基础资源与灵石消耗的经济闭环。

**P0 不要求抽卡内容完整。** 可以用 12 张代表性测试卡验证「不卡抽卡也能推进，但有卡更有策略」。

### P1 — 让抽卡和轮回成为长期驱动

1. 四种分类卡包、五档品质、卡包等级与公平累计保底。
2. 约 28～36 张有差异的功能卡，少量明确联动。
3. 重复卡升级、推荐装配与限定槽位。
4. 轮回评分、因果获取、6～8 张基础永久传承。
5. 第二世到第三世体验节奏与收益调校。
6. 本地存档版本迁移和重开选项。

### P2 — 核心确实好玩后再扩展

第四、第五张地图；更丰富的敌人词缀；命格/道侣/灵兽卡包；局内随机奇遇；图鉴；精致战斗特效、音效；广告变现与 TapTap 发行接入。

> **这次先不将广告收入列为体验优化目标**，也不因广告植入削弱玩家的自然成长。真实广告仅在玩法成立、能通过内部验收后再规划自愿激励点。

## 10. 验收标准与测量方式

### 必须通过的用户体验条件

- **前 30 秒**：能连续看到敌人被击败和首次成长。
- **前 2 分钟**：玩家做过至少 1 次有意义的属性投入；知道它为何帮助推图。
- **前 5 分钟**：应出现明确的战斗瓶颈和至少两条不同解法，而非纯随机卡包救命。
- **前 10 分钟**：多数正常试玩应能体验首次境界突破与新图解锁（并非保底倒计时）。
- **卡关后**：玩家可以解释「应该强化哪项、刷什么资源、为什么轮回值得」。
- **不抽卡挑战**：至少前一区域可依靠等级、强化和合理配置打通，抽卡不是付费墙或 RNG 墙。
- **抽卡有意义**：抽到地阶及以上，玩家能看见实际推图/产出差异；不只是卡面颜色不同。
- **局外有价值**：第二世前期明显更快，且具有至少一种不同的成长路径。
- **无死锁**：任意已进入的区域卡关后，都能刷旧关获得突破所需的基础资源。

### 可在浏览器里记录的调试指标

\`\`\`text
first_win_at / first_upgrade_at / first_draw_at
first_elite_at / first_boss_at / first_realm_breakthrough_at
deepest_stage / current_realm / wins_per_minute
stone_earned_per_minute / xp_earned_per_minute
stone_spent_training / stone_spent_gacha
time_stalled_on_stage / retry_count
reincarnation_time / fate_earned / legacy_equipped
\`\`\`

先本地记录用于模拟与调试，不上传玩家数据。避免上线后才发现大量玩家卡在同一关、或者人人只强化攻击。

## 11. 数值调试与技术拆分

新版本切忌继续在单一 HTML 里叠功能而无法模拟：应采用**配置驱动的数据模型**，把经济/战斗/地图/卡包/轮回分离。

建议最小结构：

\`\`\`text
src/
  config/
    realms.js        # 境界门槛与突破效果
    enemies.js       # 关卡、敌人与掉落表
    cards.js         # 四类卡包、卡牌与品质
    economy.js       # 强化/抽卡成本、地图收入
  engine/
    combat.js        # 纯函数：双方数值 => 交锋结果
    progression.js   # 等级、修炼、突破
    exploration.js   # 推图、卡关、扫荡
    gacha.js         # 抽卡、保底、重复卡升级
    prestige.js      # 评分、轮回与传承
  ui/
    ...              # 手机竖屏界面
  storage/
    save.js          # 本地存档及版本迁移
  tests/
    balance.js       # 批量轮回与资源流模拟
\`\`\`

工程验收至少模拟三类玩家：

1. **保守修炼**：先升级再抽卡，能否稳定突破第一图？
2. **抽卡爱好者**：优先抽卡，早期能否得到惊喜又不会完全软锁？
3. **经济投资者**：先拿建筑、再转战斗，是否有与直接强化不同的阶段优势？

此外要覆盖“极端非酋”“暴欧”“连续卡关”“传承高等级”几种状态，比较各策略第一次突破时间、最高地图深度、单位时间因果产出，不允许一种简单策略长期统治所有区间。

## 12. 当前待确认的关键设计决策

在开发 v0.2 前，优先讨论这些，不急着扩大卡牌和世界观设定。

| 决策 | 本文倾向 | 理由 |
|---|---|---|
| 首要驱动力 | 战力推进与境界突破 | 有真正可追求的目标 |
| 战斗 | 三围数值对战，少量回合 | 低成本，仍有配装意义 |
| 灵石用途 | 定向练功 + 选择性抽卡 | 保底成长与运气成长并存 |
| 道基成长 | 突破时选择一种方向 | 境界突破不只是数字涨幅 |
| 掉落范围 | 探索只给修为、灵石与抽取机会 | 守住“功能性资源必须抽卡”的规则 |
| 单局终点 | 无强制死亡，玩家择机轮回 | 更适合放置式速推成长 |
| 初版规模 | 先验证 3 张地图和 12 张样卡 | 先验证游戏性，不用内容量掩盖空转 |

### 我认为最关键的设计判据

**把抽卡按钮隐藏 5 分钟，这游戏还好玩吗？**

如果仍然有值得期待的敌人、主动强化选择、境界突破和地图解锁，它才拥有自己的骨架。再把抽卡作为稀有机缘加进来，才能使“抽卡修仙”长期成立。

## 13. 版本备注

- v0.1：已上线代码原型，四类卡包 / 装备 / 轮回可用，但结构过度依赖抽卡、战斗和境界缺少控制感。
- **v0.2：当前仅重构设计，尚未施工。** 以探索修炼与突破为核，抽卡点缀，用真实数值战斗和有效的资源支出建立长线内驱力。
- 后续只有在本文的关键决策确认后，才开始推翻与改写现有代码，避免再次出现“系统多但不好玩”的情况。
