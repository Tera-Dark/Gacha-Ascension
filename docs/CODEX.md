## 图鉴体系

- **修士与境界**：`RM-`，升级、突破、灵石修炼，不通过抽卡直接获得。
- **探索关卡**：`ST-`；敌人模板 `EN-`。
- **功法**：`GF-`，由功法包获取；灵石修炼、装配。
- **洞府**：`DF-`，由营造包获取；建造、升级、规划。
- **灵宠**：`LP-`，由御兽包获取；出战、经验、升星。
- **法宝**：`FB-`，由法宝包获取；装配与升阶。
- **丹药**：`DY-`，由丹药包获取；背包持有、服用。
- **天命遗物**：`TM-`，因果点开箱；局外全局永久叠加，**没有装备槽位**。
- **卡包**：`PK-`；五种本世 + 一种局外。

## 抽箱参数（候选）

- **天命遗物箱**：单抽 40 因果、十连 400 因果，十连不额外提高概率；单箱开出 1 件遗物。
- **基础品质**：黄 50%、玄 28%、地 14%、天 6.5%、仙 1.5%。
- **天阶及以上保底**：自上次抽到天阶及以上起，连续 19 次未出，第 20 次至少天阶。
- **仙阶保底**：自上次抽到仙阶起，连续 59 次未出，第 60 次必出仙阶。
- **叠加**：所有遗物自动生效；相同遗物叠加等级，上限后退出奖池。全部毕业后禁止继续消费因果开箱。
- **毕业重排**：剔除已满级遗物并对可获取稀有度重新归一化概率。界面必须实时展示调整后的实际概率与保底。
- **来源**：仅轮回评分结算获得因果（后续极少数一次性账号里程碑也需另行审批），不按刷怪次数持续发因果。

## 数值维护规范

1. ID 创建后不改，名称可变；避免同名不同 ID 被当作同一物品。
2. 属性效果必须标识作用系统及 `effectKey`；百分比统一以“百分点”记录，如 1.5 表示 +1.5%，不是 +150%。
3. 记录基础值、每次增益、上限、稀有度、获取途径、所属系统及提案/实装状态。
4. 所有跨系统奖励通过统一奖励结算器发放，防止重复加属性；真正的最终属性由快照纯计算。
5. 修改概率/保底必须通过模拟测试验证期望开箱次数与收集毕业进度。
6. 图鉴数值与 UI 不得各写一套；正式实装应从版本化数据注册表读取。
