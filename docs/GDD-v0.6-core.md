# 《抽卡修仙传》核心玩法冻结 v0.6 · 万物皆靠抽卡

> **2026-10-19 用户反馈后的核心纠偏。此文件优先于 v0.5 的“灵石直接三围强化”与“抽卡为点缀”说法。**  
> 现阶段是可玩纵向切片与候选数值；不是完整商业版最终平衡。  
> [可操作验收台](https://tera-dark.github.io/Gacha-Ascension/m0.html) · [M0.1 验收指南](M0-GACHA-ACCEPTANCE.md) · [当前代码](../src/m0/)

## 一句话：除了战斗，成长必须来自抽卡

**战斗打怪 → 得灵石和少量自然修为 → 把灵石投入各类卡包 → 战斗实力、资源收益、修炼速度/上限、炼丹突破都由抽卡获得 → 再挑战更高关卡。**

- **战斗唯一基本经济入口**：每场胜利提供灵石与基础修为，首通一次性额外奖励；重复旧层只有普通掉落。
- **删去“灵石直接强化三围”**：攻击/气血/防御由战力卡自动叠加；一切装备、功法、资源效率、修炼上限和境界药品都必须来自所属卡包。
- **不阻止角色基础升级**：战斗积累修为可自然提升少量基础三围；但等级**上限**和修为**获取速度**都由修为卡包提升，Lv.10 封顶后不抽修为卡无法继续成长。
- **同名重复不是垃圾**：所有永久当世被动卡“再抽到”就是自身叠层+1，自动进入正确生效组，没有“抽完还得花另一笔灵石点升级”。
- **境界有消耗型必需品**：第20层守关之后，等级至少12且通过丹药卡包取得一枚筑基丹，消耗后才能从练气突破筑基并进入第21层。
- **抽卡是主操作，战斗是获取资源和验证成长的反馈场景**。绝不再次让玩家依靠直接加点替代抽卡。

## 当前验证切片：0 → 30 层渐进体验

| 主线深度 | 解锁内容 | 玩家新决策 |
|---:|---|---|
| 初始 | 战力秘藏，初始65灵石 | 首抽保证破军剑诀（攻击+16），用抽卡见证首次变强 |
| 第5层 | 聚财机缘（灵石收益/挑战间隔） | 是继续抽战力，还是投资刷怪经济？ |
| 第10层 | 修为造化（修为倍率和等级上限） | 用抽卡突破升级天花板，提高自然修行收益 |
| 第16层 | 丹道宝匣（消耗品与突破丹） | 开始积攒筑基所需药品，倒数第8抽必获筑基丹 |
| 第20层 | 筑基境界门 | 满足 Lv.12 + 筑基丹×1 → 消耗丹药突破，继续第21层 |
| 第30层 | 青云山麓原型终点 | 地图暂不跳向未制作的新境域，仍可扫荡做卡包实验 |

**第20层为可玩原型的体验缩略门槛**：后续正式地图可以在章节末或特定大关设置境界锁。当前只是为了让用户在一次短时试玩中验证全部机制；不代表所有正式境界固定在20层。

## 四个从浅到深的卡包

| 卡包 | 解锁 | 价格（单抽） | 主要可叠加效果 |
|---|---:|---:|---|
| 战力秘藏 | 0 | 65灵石 | 攻击固定值、气血、防御、攻击百分比、三围百分比 |
| 聚财机缘 | 5 | 100灵石 | 常规战斗灵石产量、结算间隔缩短 |
| 修为造化 | 10 | 130灵石 | 修为获取倍率、修炼等级上限 +4～8 / 抽、修行属性加成 |
| 丹道宝匣 | 16 | 160灵石 | 筑基丹库存、一次性修为/三围提升丹药 |

候选稀有度权重：黄阶54%、玄阶31%、地阶12%、天阶3%；一个品质内的卡牌等权选取。所有概率为当前**单抽基础公开赔率**；十连价格为单价×10、无额外保底优势。当前四包各6张内容、共24张。未来新包归属要绑定明确的系统，不允许为了扩卡包随意发属性。

### 丹药作为门槛的公平性

- 筑基丹位于丹道宝匣的玄阶物品之一；额外设置**独立“8抽内必出”筑基丹保底**，不是在已抽出筑基丹后继续累积错误的保底。
- 十连逐抽结算，并与相同seed连续十次单抽结果一致。保证药品成为积累/规划目标，而不是运气差就永远不能通关。
- 丹药背包中保存筑基丹数量，突破时消耗一枚，所有扣药与解锁在同一事务提交。
- 本世其它丹药可以在抽出后即时转换为经验/三围增益；没有“抽出后什么都不发生”的垃圾卡。

## 自动推进 / 卡关退层恢复

1. 自动从当前目标层继续挑战，击败后立即提升通关深度。
2. **若战败**，模式切为扫荡、自动选择“最近一层已经打得过的关卡”；继续刷灵石和修为，**不扣经验、装备、丹药**。
3. 玩家抽到新卡，重新计算自己的战斗快照；若预计可以打过先前失败的新关，自动将目标改回该关继续推进。玩家也可主动点击“再闯关”。
4. 境界卡住时不是普通战败：自动扫荡第20层；即使战力够也不能硬闯第21层。只有使用筑基丹完成突破才会恢复冲关。
5. 普通扫荡不会重复领取首通奖励，已取得的最高记录保留。第30层全部完成后转为扫荡状态，不能错误访问第31层不存在的数据。
6. 战斗预测只供UI参考，真实胜负仍由逐回合交锋引擎判定。

## 资源与等级防死锁

- 新玩家初始灵石65，第一张战力秘藏可立即单抽；**首次战力单抽保证抽到黄阶破军剑诀**，完全公开，不伪装随机欧皇。
- 第1层打得过，不存在“没有灵石→抽不了卡→没有战力→连第1层都打不赢”的循环。
- 新卡包解锁时不需要先购买另一个新系统才可继续刷怪。挑战变强时总可以重复刷已击败敌人。
- Lv.10基础等级上限只被修为造化卡扩展；达到上限仍累计有限修为，抽取突破上限的卡后可以立刻继续升级。
- 聚财倍率只放大战斗灵石基础掉落，不放大永久因果、鸿蒙箱、首通累计成就或者其自身抽卡次数。
- 任何卡包都不能直接变成无条件每秒自动产生灵石的无限自反馈增长。
- 本次30关的敌方三围系数为原型平衡候选，尚未接受多策略大规模模拟；上线前要打磨空窗时长、经济回本、卡包取舍和战败频率。

## 未来系统为什么容易添加？

每新增一个系统需要：独立 \`PackDefinition\`（解锁关、价格、奖池）→ 该系统实体或效果处理器 → 账号/当世归属与保底计数 → \`EffectResolver\` 效果键 → UI自动读取注册表。它不能私自给主角改基础攻击，也不能产生一套平行资源账本。

后续系统可以包括：

- **功法卡包**：抽具体功法与功法重复强化，人物自动装配有限槽位；不同功法产生不同战斗机制；
- **洞府卡包**：抽建筑与扩建资格，改变资源获得效率、进阶产能；
- **灵宠卡包**：抽灵宠物种和同种升阶，在战斗中独立输出或护主；
- **法宝、丹道进阶、突破材料与灵根包**：各自有固定触发节点；更高境界的特定丹药也通过丹道包抽出；
- **天命遗物箱**：仅轮回后用因果抽永久加成，鸿蒙顶级掉落规则沿用 [v0.5 遗物专稿](tianming-relics-v0.5.md)，但不能反向使游戏变成只靠局外遗物升级。

**原则：系统负责消化卡牌，卡包负责产出系统内容；抽卡仍是成长的总入口。**
