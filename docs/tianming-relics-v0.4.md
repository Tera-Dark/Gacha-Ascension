## 1. 借鉴范围：Obelisk Miner 的 Relic Chests

**参考资料**：
- 社区 Wiki：<https://obeliskminer.fandom.com/wiki/Chests>；
- 社区 Wiki：<https://obeliskminer.fandom.com/wiki/Store>；
- 玩家讨论：<https://www.reddit.com/r/IdleObeliskMiner/comments/1tzdogw/early_game_relic_chests_advice_some_confusion/>。

参考游戏的遗物箱可产出**永久被动效果**；重复获得相同遗物累加其数值，不少遗物设有上限，并且达到上限后不会继续抽到。其普通、高档、特殊稀有箱子属于不同获取形式；参考资料列出的概率和付费玩法**不直接复制**。

本游戏只借鉴以下四条体验：
1. **拆箱的一瞬间有随机惊喜，叠加长期积累有明确进度**；
2. **任何遗物收集都全局生效，不强迫玩家整理遗物装备槽**；
3. **相同遗物重复抽到不是垃圾，而是该项永久加成再升一级**；
4. **满级遗物退池、可毕业、图鉴展示已收集/总层数/效果提升**。

**不照搬**：极低到不可期待的顶级掉率、最高档箱子只卖真钱、永久无限倍率通货膨胀、开一次额外赠送 N 个随机宝箱导致自我反馈失控。

## 2. 在全局系统里的位置

~~~text
探索杀怪 → 修为 / 灵石
  → 升级、训练、功法/洞府/灵宠等局内养成
  → 推进更深层数、挑战难度、突破境界
  → 主动轮回，按进度评分结算因果点
  → 消耗因果开启【天命遗物箱】
  → 获得1件永久遗物（同名直接叠加1层）
  → 全部遗物默认自动生效
  → 下一世从更高的初始效率开始
~~~

### 2.1 遗物归属

**遗物是 MetaState 的永久资产，不是普通背包物品。**

- 遗物界面：位于【天命 → 遗物图鉴】及【轮回结算 → 开启天命匣】。
- 背包界面：可以只读展示已经取得的遗物/效果，但不维护第二份数值或掉落库存。
- 无法放入功法/法宝槽位；不允许出售、拆解、卸载、重铸以获得无限因果收益。
- 所有已拥有遗物在每一世**从开始到结束**自动生效；当前要实现的是纯被动，未来可扩展标签套装但不能破坏自动生效的承诺。
- **原 v0.3 的“三槽永久传承”暂时废弃**：本方案由无槽永久遗物承担局外成长。将来如确需“开局选择三个天命”，另起不参与遗物池的“先天命格”系统，防止重复永久增益层。

### 2.2 资源边界

- 因果点的**常规、唯一可重复来源**：本世轮回评分。
- 战斗可以获取灵石、修为，不直接掉遗物、遗物箱、因果点。
- 轮回结算可以直接发因果点，由玩家决定何时开遗物箱。
- 原始灵石无法兑换因果；局内功能包和局外天命匣不会共用货币。
- 遗物可以提高当世刷图、成长、修为收益，却**不能直接加成轮回评分或因果点产量**，以免造成指数级的货币生产闭环。

## 3. 天命箱规则

### 3.1 单箱和十连

| 项目 | v0.4 候选值 |
|---|---|
| 普通天命匣单抽 | 40 因果 |
| 十连 | 400 因果；与十次单抽完全同赔率、同保底进度 |
| 每抽内容 | 1 件遗物，直接进入永久遗物图鉴 |
| 初始稀有度 | 黄 50%、玄 28%、地 14%、天 6.5%、仙 1.5% |
| 天阶及以上保底 | 连续 19 抽不出天阶及以上，第 20 抽至少天阶 |
| 仙阶保底 | 连续 59 抽不出仙阶，第 60 抽必出仙阶 |
| 进度 | 账号永久保存；十连中逐抽更新 |
| 遗物上限 | 各自单独上限（8–30 层）；满级从后续可抽池剔除 |
| 最高毕业状态 | 如果全部遗物已满级，不能继续扣费开箱 |

**概率是初始池配置**。毕业退池后所有可取得品质的实际概率需要实时重新计算并公示；不可继续对玩家展示未变化的 50/28/14/6.5/1.5。

### 3.2 保底判定优先级

1. 查看是否全部毕业；如已毕业，禁止扣费。
2. 根据已达上限的遗物过滤当前候选对象。
3. 优先检查**仙阶保底**（第 60 抽），如仍有仙阶可抽，强制仙阶；如该档已毕业则其保底视为达成并停止计数。
4. 检查**天阶及以上保底**（第 20 抽），在可用天/仙档中按剩余有效权重抽；两档均毕业则该保底不适用。
5. 非保底：按当前有合格对象的品质重新归一化原始权重，从该档全部未满级遗物中等权随机一件。
6. 发放该遗物的 +1 层，**然后**更新两类保底计数；天阶及以上重置天阶计数，仙阶同时重置两类计数。
7. 一次事务提交扣款、计数、图鉴、结果日志，任何失败不得出现因果已扣却未获得物品。

说明：保底“连续 19 抽不出”是指第 20 抽为强制；只保证品质，**不指定具体遗物**。在一档已被全部抽满时，系统不降档来“假装兑现”，而是隐藏该档已毕业的保底提示。

### 3.3 封顶及退池算法

假设玄阶 6 种遗物中有 3 种满级：

- 若抽中了玄阶，从剩下 3 种中等概率选择一个；
- 如果玄阶 6 种都满级，该档有效权重为 0；在其余可用档的原始权重中重新归一化；
- 玩家每次开箱前能看到“玄阶：已毕业”，以及新的**真实**单抽概率；
- 不要额外发一个“遗物灰烬”币种，也不要强行给满级遗物做折价返还；把退池机制作为天然防浪费；
- 在最后一个未满级遗物被抽到后，下一次箱子显示“全部毕业”，禁止再开，不扣因果。

**这样低阶卡会自然毕业，高阶卡在后期更常被抽到。** 但高阶并非只能等到低阶全部毕业后才出现，正常玩家从第一抽就有概率获取所有品质。

### 3.4 免费玩家的期望（需要验证）

以固定初始概率、不考虑保底/退池的粗略值：
- 天阶及以上理论基础单抽概率为 **8%**；
- 仙阶理论基础单抽概率为 **1.5%**；
- 由于有 20/60 抽保底，实际长期获取速度高于上述单纯几何分布的情况；
- 前 1–2 次轮回至少应足以开一次普通天命匣；不能要求首次通关就刷上百次轮回。

**正式版本必须用 10,000+ 个随机种子的离线模拟**验证：第 1/5/10/20 次轮回平均获得的遗物层数、稀有度分布、完成 50% / 90% / 100% 的抽数分布。图鉴不应靠设计者凭空猜“多久能毕业”。

## 4. 图鉴与属性：所有加成都要有系统归属

遗物共 **30 件：每品质 6 件**。具体每件的 ID / 单层值 / 上限以 CSV 为准：

- **修士类**：直接增加主角基础攻击、气血、防御，或按比例提升。
- **探索类**：提高常规战斗灵石/修为收益、辅助本世等级成长。
- **境界类**：提高突破给予的属性奖励，不增加突破所需基础门槛。
- **功法类**：提高已装配功法的正向效果，不会凭空生成不存在的功法。
- **洞府类**：提高已安置建筑的经济加成，不凭空在未建洞府时产出资源。
- **灵宠类**：提高宠物经验/伤害，或由出战宠物给予首回合护盾；无出战宠物时效果允许暂时为零。
- **战斗类**：Boss增伤、穿透、防护，是针对难关的永久成长。
- **抽卡类**：提高**本世功能卡包**获取经验的速度，不会提升永久天命匣的掉率、品质或出箱次数。

### 4.1 单件叠加公式

~~~text
relicCopies[id] 是该遗物的永久已获得层数
0 <= relicCopies[id] <= relic.maxStacks

遗物原始属性贡献 = relicCopies[id] × valuePerStack

同 effectKey 的遗物贡献统一加算（不先逐层复乘）
比如：
  TM-007 太初锋印：每层攻击 +1.5%，获得8层 → +12%
  TM-019 乾坤剑胚：每层攻击 +3%，获得2层 → +6%
  两者组成的攻击百分比遗物组 = +18%（不是 1.12 × 1.06）
~~~

**总图鉴中展示的是原始加成，最终属性须结合基础修士、功法、境界、灵宠等其它加成算出。** 因此不能把“最多获得的所有加成总和”简单说成最终战力上限。

### 4.2 各效果的明确定义

| effectKey | 生效位置 / 定义 | 边界 |
|---|---|---|
| attackFlat / hpFlat / defenseFlat | 加到修士基础三围，先于百分比增益计算 | 可与升级/淬炼叠加 |
| allBaseStatsPct | 对主角三围统一基础倍率 | 同组先相加再乘，不包含灵宠 |
| attackPct / hpPct / defensePct | 对主角对应基础属性加百分比 | 同 key 加算 |
| stoneGainPct / cultivationGainPct | 战斗结算的原始基础灵石/修为奖励加成 | 不加到首通独立奖励或因果 |
| allResourceGainPct | 常规战斗灵石/修为基础奖励同时提高 | 与对应资源专属加成在同组相加 |
| caveYieldPct | 放大**已建造建筑对资源的增益数值** | 无建筑不会凭空产资源，不能重复乘整体收益 |
| petExpGainPct | 宠物在参战后经验收益提高 | 未出战宠物不受影响 |
| petDamagePct | 宠物实际造成的伤害提高 | 主角普通攻击不吃此加成 |
| petFirstTurnShieldPct | 出战宠物提供一次等于主角最大气血一定比例的首回合护盾 | 每场仅一次，且只有出战灵宠时生效 |
| techniqueEffectPct | 提高已装配功法**正向数值效果** | 不强化负面效果、不会产生额外槽位 |
| armorPenPct | 计算本场对敌方造成伤害时穿透一部分防御 | 所有来源合计最高 60% 穿透 |
| damageReductionPct | 伤害公式结算后的受伤减免 | 所有来源合计最高 60% 减伤 |
| bossDamagePct | 对守关与境域 Boss 增伤 | 对普通怪、精英怪无效 |
| breakthroughBonusPct | 境界突破时新增的属性成长幅度提高 | 不追溯改变旧境界提升结果，避免存档属性污染 |
| trainingCostReductionPct | 修士灵石三向强化成本降低 | 与其他折扣合计最高减价 60%，最低成本至少 1 灵石 |
| runPackExpGainPct | 抽取本世功能卡包时，每抽经验从1变成1×(1+加成) | 经验可小数累积；不影响天命遗物匣 |

### 4.3 防止无限倍率膨胀

**严禁遗物加成的增量再次作用在其自己的产出端**（例如永久天命匣给更多永久天命匣、因果点倍增），除非未来独立完成闭环证明与封顶设计。

全局硬帽候选：
- 破甲总效果：**≤60%**；
- 实际受伤减免：**≤60%**；
- 灵石强化总成本折扣：**≤60%**；
- 首回合灵宠护盾：**≤主角最大气血的 35%**；
- 功法正向效果总加成：在当前 30 件遗物的满级组合下有上界，可暂不附加更低的隐藏帽；以后新增跨系统加成必须另测；
- 稀有卡包提升与遗物图鉴的属性不能合并为同一连乘链，除非经过手动批准。

### 4.4 效果计算优先级

~~~text
（A）基础属性：修士等级 + 灵石训练 + 境界突破已获得的固定增量
（B）固定值：遗物固定 attack/hp/def
（C）基础全属性百分比：allBaseStatsPct
（D）对应三围百分比：attackPct / hpPct / defensePct（+功法/法宝等合规增益）
（E）本场固定出战单位：主角 + 灵宠、装备功法、法宝
（F）战斗局部乘区：Boss伤害、破甲、减伤、首回合宠物护盾
（G）结算经济：基础奖励 × (1 + 资源专属 + allResource + 洞府建筑有效加成)
（H）增益最终舍入、最低收益/成本限制
~~~

示例：原始战斗掉落 100 灵石，遗物灵泉滴露 4 层（+8%），万象归一印 2 层（+4%），洞府建筑提供基础 +20% 收益且聚宝星盘 3 层（每级提高建筑加成 +3%）。最终建筑部分为 20% × (1+9%) = 21.8%；战斗掉落按单一收益加法组得 **floor(100×(1+0.08+0.04+0.218)) = 133 灵石**。绝不能把 100 先乘遗物，再乘洞府，再乘其它收益，这会令后期雪球失控。

## 5. 轮回评分与开箱节奏

与 v0.3 旧公式相比，新的轮回评分必须和遗物抽卡价格相匹配：

~~~text
Score = 12 × 本世普通主线最高推进总层数
      + 100 × 本世已突破的大境界次数
      + 20 × 本世首次击败的精英/区段守关（单个成就只算一次，封顶）
      + 难度首通的有限加成

Fate = floor(Score / 10)
首次有效轮回条件：本世首次完成青云山麓第30层
~~~ 

举例：第一世推进到普通第30层、完成首次筑基突破、首次击败两位区段守关，则 Score = 360 + 100 + 40 = 500，得到 **50 因果点**，足够开启一次 40 因果的天命匣。

**这只是平衡起点**，需测试不同轮回深度的单位时间因果效率。若快刷第30层长期最优，应调高更深境界里程碑奖励或修改评分，而不是偷偷降低第30层掉落。

轮回结算后因果存入 MetaState，再打开遗物界面消费；**本世中不能一边继续推进一边实时兑现同一世的轮回因果点**。这样才能保持轮回决策的取舍。

## 6. 图鉴与 UI 设计

图鉴页应该让玩家迅速看清“抽过哪些、当前有什么用、还差多少可以毕业”，而不是一页 30 张大型立绘：

~~~text
天命遗物
当前永久叠层 68 / 总可叠层 498     [仅显示未满级]
[全部] [战斗] [修士] [经济] [功法] [洞府] [灵宠] [抽卡]
[按稀有度] [按获得次数] [按对当前目标贡献排序]
---------------------------------------------------
黄 · 炼体余烬       +2 攻击 / 层      8 / 30
玄 · 聚宝星盘       建筑增益 +3%/层   2 / 20
天 · 乾坤剑胚       攻击 +3% / 层     1 / 12
仙 · 道源天书       功法加成 +7%/层   0 / 10（未获取）
---------------------------------------------------
本账号合计加成：[攻击 +X] [修为 +Y] [洞府 +Z] ...
抽取次数：N  |  下次天阶保底差 X 抽  |  仙阶保底差 Y 抽
[开启一次：40 因果]      [开启十次：400 因果]
~~~

### 图鉴信息要求

每件遗物详情至少有：
- 稳定 ID、名称、稀有度、加成所属系统；
- 每层数值与单位、当前层数、上限层数、当前总原始增益、下一级提升；
- 生效条件（例如“必须有灵宠出战”）；
- 达到上限时是否退池；
- 对当前战斗/资源面板贡献的**本次实际效果**；
- 解锁状态、适用版本，参数是否已实装。

### 不做的图鉴交互

不设计随机重铸词条、遗物装备槽、赛季专属跨期无法获取、付费档隐藏遗物，避免收藏游戏性变成存量管理压力。

## 7. 迁移和技术边界

### 7.1 账号状态建议

~~~ts
type RelicMetaState = {
  fatePoints: number;
  relicCopies: Record<string, number>;     // id → 0..maxStacks
  relicDrawCount: number;                   // 总抽数（永久）
  heavenDryStreak: number;                  // 连续未获天阶+
  immortalDryStreak: number;                // 连续未获仙阶
  relicReceipts: Array<{ txnId: string; relicId: string; before: number; after: number }>;
};
~~~

收据日志可限量（例如最近 100 笔），但**拥有数量**与**保底进度**是不可删的账号持久数据。保底数字不属于当前轮回，绝不随轮回重置。

### 7.2 旧存档

- v0.1 已有老 \`legacyOwned\`/传承抽卡，本系统不同于旧定义，**禁止静默把旧存档当成新遗物图鉴**；
- 开发迁移时提供“旧档保留／迁移确认／新档”明确策略；
- 若制定旧传承补偿，需要显式可查的对照表与确认，不可暗自清除因果与原有传承。

### 7.3 验收自动测试

- 给所有 30 件遗物分别设定0/1/满级，在 10,000 次抽箱模拟中确认不超上限、不抽到已满级；
- 100 个不同 RNG 种子验证天阶/仙阶保底均在约定次数内触发；
- 单抽 10 次与十连 1 次用相同 seed、同一初始状态，掉落相同且消费相同；
- 因果余额不足时不得扣费，也不得推进 pity；
- 30 件全部满级时，禁止开箱并且不扣因果；
- 装配功法/灵宠/洞府后效果即时变化，卸下立刻还原，不需要清除遗物永久状态；
- 无宠物出战时，宠物相关加成不应污染主角攻击；
- 账号切换轮回后遗物不会丢失，也不会重复叠加；
- 总图鉴与数据文件同版本、同 ID，不允许手写两套数值。

## 8. 可能的未来拓展（与首版隔离）

1. 通过某些成就奖励特殊品质保底箱（只能来自免费游戏里程碑，不能付费独占）。
2. 境域图鉴完成度提供纯展示徽章、额外被动分类统计；不要立即额外再做一套全局倍率。
3. 若后期真需要主动选择三张先天命格，可与被动遗物独立建模，**命格占位、遗物不占位**。
4. 新增品质前必须先评估现有五阶卡池的毕业体验、稀有度分布与天阶保底是否需要修订。

**当前结论：一个天命遗物箱 + 30 件持久被动遗物 + 有限叠加 + 满级退池 + 可查图鉴，是足够完整的第一版永久收集系统。**
