## 1. 五个大境界与20个小境界

修士没有数字等级，UI必须直接显示「炼气·初期」「金丹·后期」「化神·圆满」等名称，以及下一次突破所需资源的进度。

| 大境界 | 小阶段 | 主要成长质变 | 跨大境界需要的特殊丹药 |
|---|---|---|---|
| 炼气 | 初期 → 中期 → 后期 → 圆满 | 初次形成丹田，灵气吐纳、基本战力增长 | 筑基丹 |
| 筑基 | 初期 → 中期 → 后期 → 圆满 | 道基稳定，功法与体魄开始出现流派特长 | 凝金丹 |
| 金丹 | 初期 → 中期 → 后期 → 圆满 | 内丹凝成，主动法术/灵宠协同更突出 | 结婴丹 |
| 元婴 | 初期 → 中期 → 后期 → 圆满 | 元婴出窍，法相与多阶段Boss开始出现 | 化神丹 |
| 化神 | 初期 → 中期 → 后期 → 圆满 | 神识化形，法则、抗性与领域战斗逐渐重要 | 渡劫道丹（飞升试炼） |

**共同规则：**
1. 初期→中期、中期→后期、后期→圆满为**小境界突破**，需要修为储备 + 通过修为造化包积累的悟道进度，不需要指定高稀有卡或专门丹药。
2. 圆满→下一大境界初期为**大境界突破**，需要修为储备 + 悟道进度 + 丹道卡包抽出的指定突破丹 + 击败该境界地图序列末尾的关底Boss。
3. 最终化神圆满→飞升不加入第六境界：要求飞升劫台最终Boss、渡劫道丹和足够的修为/悟道，完成后记录「飞升成功」，作为此版本终局。
4. 突破必须玩家主动执行并播放演出；修为满但条件未齐时保持圆满/当前小境界，可继续积累资源；不会因自动战斗擅自消耗丹药。
5. 修为成本与悟道成本**逐次上升**，跨大境界有额外的战力质变。不能通过输入金钱或灵石直接购买境界。
6. 突破成功时永久改变**本世**的境界基础乘区和可用战斗机制；无数字等级、经验等级被动升级或等级上限卡。

### 修炼抽卡的核心职责

为避免修士只是「挂机杀怪→修为满自动升级」，特设**悟道进度**：

- 战斗只掉基础「修为」和灵石；不直接掉悟道令牌、功法、灵宠、突破丹。
- 每次抽「修为造化」包必得至少1点悟道进度（卡池里的罕见奖励可以给更多悟道或修为/修炼效率加成）。因此**每一次修炼相关抽卡必定推进突破**，运气差也不会永久卡死。
- 每次突破消耗规定数量的修为与悟道；未消耗的进度保留，本世重新突破时仍有效。
- 丹道包产出筑基丹／凝金丹／结婴丹／化神丹／渡劫道丹，五种按当前大境界公开解锁；每种目标丹单独统计保底，避免被其它丹药刷新保底计数。
- 其它功能卡仍从战力、功法、洞府、御兽、法宝等卡包获得。**不用灵石直接购买「经验」「境界等级」或「装备强化级」。**

## 3. 每张地图内部的关卡设计

| 地图位置 | 地图内关卡数量（候选） | 一次失败后的行为 | 对应体验 |
|---|---:|---|---|
| 地图1–4 | 6–8段 | 当前关的小怪无限可刷；不扣战利品 | 前期密集、高频解锁 |
| 地图5–8 | 8–10段 | 持续积累灵石/修为直到能打赢守卫 | 筑基后系统互相配合 |
| 地图9–13 | 10–12段 | 可持续经营同关小怪，养成洞府与功法 | 金丹开始明显需要长线积累 |
| 地图14–18 | 12–14段 | 强化流派后再尝试精英/首领 | 元婴阶段数值高墙 |
| 地图19–24 | 14–16段 | 允许离线安全刷当前已解锁的**小怪**（须离线系统实装） | 化神中后期需要长时间经营 |

**单个关卡的状态机：**

~~~text
解锁新地图 → 解锁第1关的小怪刷新点
  ├─ 自动刷本关小怪（始终可刷，获得修为和灵石）
  ├─ 达到挑战阈值后 → 挑战当前关卡守卫
  │    ├─ 胜利 → 领取一次性首通权益，开放下一关和其小怪
  │    └─ 失败 → 原地继续刷**当前关卡的小怪**，等待玩家抽卡/换构筑
  └─ 最后一关守卫 / 地图专属Boss
       ├─ 胜利 → 当前地图通关；满足大境界条件后解锁下一地图
       └─ 失败 → 仍可刷**当前关卡的小怪**，不退层
~~~

- 小怪实力必须明显低于该关守卫；设计为玩家**已击杀至少一次**的小怪才能设置为长期自动刷目标，保证不会因为突发属性变化完全没有经济来源。
- 守卫 / Boss 是**独立挑战事件**，不会自动代替小怪无限重试。自动推进模式只在有明确胜算、达到最低资源阈值或玩家手动许可时尝试；失败后进入冷却/发育，不连续送死。
- 每张地图至少三种小怪生态差异、一种精英词缀和一个有专属能力的Boss；后期同地图守卫可组合多种词缀。
- 小怪刷怪掉落**基础灵石和修为**；不掉突破丹、装备、功法、灵宠或免费虚构的境界升级。首通允许发放一次性的指定卡包免费抽资格，但真正内容仍从卡池产出。
- UI 主屏幕优先显示：「地图 / 当前关 / 当前小怪 / 下一守卫 / 下一张图Boss / 当前境界突破进度」；增加「一直刷小怪」「尝试守卫」「自动挑战Boss」三种清楚的动作。

## 4. 指数增长公式（设计候选，必须经过模拟调参）

### 4.1 修为与悟道资源

定义当前修炼境界从0到19依次为「炼气初期=0」「炼气中期=1」……「化神圆满=19」。

- **升级所需修为：** \`QiCost(i) = ceil(100 × 2.35^i)\`，i=0至18；i=19对应飞升劫前的最终修为储备。
- **升级所需悟道：** \`InsightCost(i) = ceil(1 × 1.26^i)\`，每次抽修为造化包必得至少1点，抽中的卡还可提升获取倍率/额外悟道。未消耗悟道不丢失。
- **每次突破时扣除实际要求的修为和悟道**；超过阈值的库存保留，不能因为突破直接归零。
- **小境界稳健基础跃升**：本世三围基础乘区提高约×1.18～1.30（候选），不受某一高稀有卡强制决定。
- **大境界跃升**：基础乘区额外获得约×2.2～×3.0 的一次性质变（候选），同时可开放新的法术/宠物战斗阶段。
- 修为只能通过怪物胜利、已抽取到的修为卡即时奖励或其乘区增长；悟道必须由修为抽卡积累，**不能直接花灵石购买悟道值**。

示例成本（采用候选公式、四舍五入）：

| 突破目标 | 当前状态序号i | 本次修为消耗 | 丹药 |
|---|---:|---:|---|
| 炼气初期→中期 | 0 | 100 | 无 |
| 炼气圆满→筑基初期 | 3 | 1,298 | 筑基丹×1 |
| 筑基圆满→金丹初期 | 7 | 39,580 | 凝金丹×1 |
| 金丹圆满→元婴初期 | 11 | 1,207,109 | 结婴丹×1 |
| 元婴圆满→化神初期 | 15 | 36,814,418 | 化神丹×1 |
| 化神圆满→飞升 | 19 | 1,122,766,338 | 渡劫道丹×1 |

这些数字说明的是**绝对成本指数增长**，不直接等价于需要挂机多少小时；后期小怪收益也在指数增长。真正的时间成本要按每张地图可持续获得的修为/分钟、抽卡所需灵石/分钟统一校准。

### 4.2 地图强度、掉落与守关倍率

地图序号m为1至24，地图内守卫序号k从1递增。首版用**配置驱动的指数基线**，不用手工写出几千个彼此独立的属性：

~~~text
MobHp(m,k)        = round(65 × 1.85^(m−1) × 1.13^(k−1))
MobAtk(m,k)       = round(13 × 1.70^(m−1) × 1.09^(k−1))
MobDef(m,k)       = round(4  × 1.72^(m−1) × 1.08^(k−1))

StoneDrop(m,k)    = round(12 × 1.66^(m−1) × 1.07^(k−1))
Cultivation(m,k)  = round(10 × 1.67^(m−1) × 1.07^(k−1))

GuardianHp        = 当前关小怪Hp × 3～5
GuardianAtk       = 当前关小怪Atk × 1.8～2.8
MapBossHp         = 当前关小怪Hp × 6～12
MapBossAtk        = 当前关小怪Atk × 2.5～4
~~~

- 上述数值是**待调候选**，不能未经模拟直接当做生产平衡。怪物属性和奖励都指数增长，但Boss涨幅明显高于普通小怪，产生需要停下积累的「墙」。
- 地图机制影响守关解法，不能只用Boss血量10倍充当特色：减益层数、护盾、回血、法相、场地效果等应通过战斗引擎共用Effect/MechanicResolver。
- 大境界转换处可以引入「区域强度跨图修正」，但必须集中在配置而非每张图堆 if 条件。
- 地图通关后的下一张图收益明显提升，但也不能使旧地图所有卡/洞府瞬间失效。设定最低/最高收益增益硬帽以抑制跨系统复利无限溢出。
- 用大数可读格式显示：万、亿、兆、万亿等；如果后续扩展超过JavaScript安全整数上限，改用Decimal/BigInt+序列化字符串，不能出现精度损失、Infinity、NaN。
- **不要以「每地图要挂机几小时」硬性卡进度**；目标在于玩家可看到储备增长、抽到有用卡、缩短下一次突破时间。

### 4.3 每个阶段希望的「积累感」

| 游戏阶段 | 典型积累行为 | 内容解锁密度 |
|---|---|---|
| 炼气前2图 | 一边推图一边第一次抽到战力和修为能力，几次击杀可抽第一张 | 密集、教学友好 |
| 炼气后2图 / 筑基前半 | 首次较长时间卡关，选择功法或经济路线 | 仍较密集，开始考验投资 |
| 筑基后半 / 金丹 | 一次大境界需要多次卡池投资与战斗验证 | 新系统解锁放缓 |
| 元婴 | 高级丹药保底、宠物与功法进阶、洞府经营 | 少量重要里程碑，更多积累过程 |
| 化神 | 以法则机制、境界资源、顶级遗物与最终飞升目标为主 | 稀疏但重量级的功能/内容 |

**密度建议**：前4图每1–2图就有新内容体验，中期每3–4图才开放重大系统，末期每5–6图才出现一次全新大系统。但本轮用户要求先规划地图和境界，**暂时不冻结具体系统解锁序号**；实现时必须读配置，可随时修改。

## 5. 丹药与跨境公平性

| 大境界门槛 | 目标丹 | 获取方式 | 保底原则 |
|---|---|---|---|
| 炼气→筑基 | 筑基丹 | 丹道宝匣（当前阶段池） | 至多8次对应阶段丹道抽卡 |
| 筑基→金丹 | 凝金丹 | 丹道宝匣·金丹篇 | 至多12次对应阶段丹道抽卡 |
| 金丹→元婴 | 结婴丹 | 丹道宝匣·元婴篇 | 至多16次对应阶段丹道抽卡 |
| 元婴→化神 | 化神丹 | 丹道宝匣·化神篇 | 至多20次对应阶段丹道抽卡 |
| 化神→飞升 | 渡劫道丹 | 丹道宝匣·渡劫篇 | 至多24次对应阶段丹道抽卡 |

- 保底次数是**候选参数**，按当前地图经济/单抽价格进行配平，不要求某项高稀有卡必须出货。
- 丹道包可按境界分组，也可共用入口切换**阶段独立子池**，避免旧丹药稀释新境界材料并导致抽卡浪费。
- 保底按目标丹分别计数，不被其他丹药重置；不因轮回意外删除账号级赠抽声明（普通局内丹药库存跨轮回仍按重置契约）。
- 同一地图Boss/境界守卫被击败不直接给予丹药，只解锁突破资格，避免违背「万物靠抽卡」。

## 6. 地图推进和境界成长是两个互相制约但独立的状态

~~~text
MapProgress:
  unlockedMapId, currentMapId, currentCheckpoint,
  clearedGuardians[], defeatedMapBosses[], farmTargetId
  // 同地图当前关小怪不受失败回退影响，Boss打败才解下一图

CultivationState:
  majorRealmId, minorStageId, currentQi, accumulatedInsight,
  pillInventory // 由对应卡包提供
  // 没有 level、levelCap、heroXPLevel

BattleActivity:
  kind = farm_mob | challenge_guardian | challenge_map_boss | paused
  autoFarm, retryPolicy, completedFights
~~~

- 战斗状态不再使用旧版「失败→上一层 farmFloor」规则；
- 局内Run保存当前地图、小怪刷新点、功法/灵宠/洞府/修为；Meta保存账号已解锁系统、最佳地图Boss、永久遗物与轮回统计；
- 轮回从地图1重新开始，但账号层的系统开放资格可以保留，避免再次解锁冗长新手引导；
- 地图24飞升的**终局飞升结算**与主动轮回的**跨世天命结算**必须分离，飞升不是必须重开档；
- 同一个阵营守卫或Boss第一次击败只给一次里程碑收益，反复刷小怪不会伪造Boss首胜/轮回因果。

## 7. 轮回在长地图体系中的位置

因为飞升在第24张图，若把第一次轮回强行锁定到飞升，玩家可能积累过久才体验到游戏长线机制。因此建议：

- **地图4与筑基达成后**允许首次主动轮回（前期可选择领取至少一个常规天命箱的合理因果目标，需平衡模拟）。
- 地图8/13/18/24为较大奖励跃迁节点；越后期同世继续挑战，单位时间因果收益可能更好，但轮回永远是玩家自愿选择。
- 常规天命遗物是稳定永久成长，太古十万分之一、鸿蒙百万分之一独立追加，均无保底，不作为任何地图Boss/飞升的入场条件。
- 允许玩家在当前境界继续经营或自愿轮回，避免「陷入等待只能重开」或「轮回唯一最优」。
- 天命效果对数值的大幅提升使用明确乘区硬帽；地图指数曲线与遗物永久叠层共同校准，不能让多次轮回之后玩家跳过整个游戏的机制Boss。

## 8. 与当前代码的迁移、开发和验收计划

**已在独立 preview-v0.8.html 试玩页实现前4图，不覆盖历史 m0.html 的 v0.7.1 存档。** 完整24图、额外境界及未来跨Schema版本仍必须制定迁移方案：

1. **先建立24张地图权威配置**：稳定mapId、mapIndex、背景环境、生态、阶段数量、BossId、机制、指数倍率；保存25个以上主要敌人行为原型不写死在UI。
2. **再替换角色等级模型**：20个小境界、独立Qi/悟道资源、按公式消耗、对应丹药阶段池、主动突破和跨境守卫门槛。
3. **重写地图状态机**：小怪刷怪、守卫挑战、Boss挑战、Boss解锁新图、失败只刷当前关小怪，安全重试而不是自动退到旧关。
4. **接入现有系统**：战力/功法/洞府/灵宠/修为/丹道仍从卡包产出。可调解锁节点后移为统一UnlockRegistry，不在UI写死。
5. **最后统一数值模拟**：从首图到24图，低稀有保底策略、经济流、战力流、坏运种子、跨境丹药保底、轮回遗物增益，以及飞升终局的长期成本统计。
6. **发布新预览入口**，保留原工作台以对照；不可在新的20境界模型稳定前覆盖现有M0、M0.1、M0.2本地存档。

### 必须通过的硬测试

- 20个小境界顺序正确，不出现Lv.1/Lv.99或按等级自动升级；
- 24图按稳定顺序开放，击败非地图Boss不会错误开放下一图；
- 当前关守卫/Boss失败后，不退到上一关；始终有可刷、打得过、会产出资源的当前关小怪；
- 所需修为、悟道、突破丹阶段逐步增加且均可通过战斗→抽卡循环取得；任意自然坏运种子不因关键丹药而无限死锁；
- 前几张图推进较快，越往后明确需要更大规模投入；不能只靠随手多抽1张卡连续秒掉5张地图；
- 大境界突破必须同时满足修为、悟道、目标丹和对应地图Boss，不能通过前端按钮或自动冲关绕过；
- 传统炼气、筑基、金丹、元婴、化神五境清晰展示，最后飞升成功而非莫名其妙突然出现一个数字等级；
- 所有数字都有限且安全，离线刷小怪（未来接入时）不能凭空越过守卫/Boss或重复领取首通；
- 主要系统仍然依靠卡包获得，不恢复直接花灵石加攻防血的旧设计。

### 暂不冻结的内容

- 功法、洞府、灵宠、法宝、丹道高级池与天命的最终系统解锁节点；
- 单张地图的精确关数、动画长度、刷怪平均分钟数；
- 主要Boss技能倍率、小怪收益、当前24图是否都要有独立特殊卡包；
- 化神飞升后的天界地图与更高修为境界（本稿止于飞升）。

**规划结论：**本版世界不是「一个30关章节」而是「24个逐步解锁的修真区域 + 20个境界状态 + 指数型修为/战斗/资源曲线 + 不强制的主动轮回」。玩家可以在每一个地图当前关卡稳定积累，小目标是下一守卫，中目标是下一地图Boss，大目标是大境界突破，终极目标是化神圆满后成功飞升。
