## 遗物箱实际概率

- **常规箱**：40因果/箱；五档常规基础权重黄50%、玄28%、地14%、天6.5%、仙1.5%，常规第20箱内至少天阶+、第60箱内至少仙阶（仍有该品质可抽时）。
- **鸿蒙额外判定**：每箱独立 **0.01% = 1/10,000**，无保底、不会被常规天仙保底影响，中奖在常规奖励之外追加1件。
- 尚未拥有全部4件时，抽中后在**未获得**的鸿蒙异宝中等概率挑选，已获得的退池；第一件指定异宝的单箱概率为0.0025%。
- 常规遗物满级时移出常规奖池；所有常规满级后抽箱结算共鸣进度，继续进行鸿蒙判定。
- **主线/普通成就没有任何一项强制要求鸿蒙遗物**，极稀有只是长期上限追逐。

## 需要实际测算的内容

1. 以轮回因果/时间实际获取率，估算账号平均每世开多少天命箱；是否支撑万分之一长期追求。
2. 测试普通毕业后共鸣是否引发数值通胀；满共鸣仅额外增加基础三围10%。
3. 模拟获得一件鸿蒙后不同流派究竟缩短多少 Boss 战斗回合，不能意外突破引擎硬上限或溢出。
4. 功法/洞府/御兽三条路线的首次30层时间分布，验证常规成长乐趣。
5. 关卡解锁阈值触发是否仅发生一次，以及是否在当前开发阶段有可使用的内容。

ID 规则：`TM-`天命遗物，`GF-`功法，`DF-`洞府，`LP-`灵宠，`FB-`法宝，`DY-`丹药，`ST-`关卡，`EN-`敌人，`RM-`境界，`PK-`卡包，`UL-`解锁节点。

**状态仍为 proposal/example_only。研发时必须先做核心可玩循环，再把新图鉴配置切换成 implemented。**
