# 《抽卡修仙传》v0.8.2 · Melvor Idle 战斗机制拆解与本项目深度改造

> **类型：研究对照 + 已实现代码说明 + 后续规划。** 2026-10-20。
>
> 当前可玩入口：[v0.8 四图独立试玩](https://tera-dark.github.io/Gacha-Ascension/preview-v0.8.html)；旧v0.7.1不受影响。  
> 本稿中「Melvor原作」指参考机制，「项目改造」是独立原创数值与规则，**不是复制 Melvor 的公式、职业名称、掉落、数值和美术**。

## 1. 从 Melvor Idle 研究到的核心战斗设计

### 1.1 游戏需要「可计算的风险」，而不是单一战力值

Melvor具有**准确度评分（Accuracy Rating）与回避评分（Evasion Rating）**的命中关系，近战/远程/魔法角色会有不同的战斗风格；攻击和力量影响命中及潜在伤害、Defence更多影响闪避，而独立的 Damage Reduction（伤害减免）直接关系是否能安全挂机。命中判定/减伤/防御必须在界面可读，玩家才知道换装备的理由。

- 参考官方Wiki：[Beginners Guide, Basic Combat](https://wiki.melvoridle.com/index.php?title=Beginners_Guide)
- [Combat Triangle](https://wiki.melvoridle.com/index.php?title=Combat_Triangle)
- [Defence](https://wiki.melvoridle.com/index.php?title=Defence)

**本项目改造：**我们不设置Melvor的Attack/Strength/Defence/Ranged/Magic数值等级，依然只有「修士三围 + 炼气/筑基境界」，但在战斗层派生出 *命中、回避、减伤、流派克制与攻击间隔*。让同样的攻击力配不同功法时面对不同Boss有不同表现。

### 1.2 地下城是「连续遭遇与保命计算」

Melvor地下城挑战不只是单挑一个Boss，而要评估多类怪物/特殊攻击，回血与伤害减免直接影响是否有能力自动持续挑战。社区经验尤其强调根据敌人的**最大有效单次伤害和补血阈值**来判断可否挂机。

- [Melvor Wiki FAQ, Combat Death and Auto Eat](https://wiki.melvoridle.com/index.php/FAQ)
- [Melvor相关减伤与地下城安全挂机资料](https://github.com/gridster2/Melvor/blob/main/Documents/Compendium%20of%20Damage%20Reduction.md)
- [Melvor Combat Progression Guide](https://gameplay.tips/guides/melvor-idle-combat-progression-guide-toth.html)

**本项目改造：**普通小怪为单战斗，关卡守卫变两波，地图Boss变三波。多波之间角色不回满血，灵宠护盾不重复刷新，只有全部击败才发守关/地图里程碑收益。失败保留当前位置、不发Boss奖励，可继续刷当前小怪。此处特意不加入 Melvor 的装备掉落/消耗食物路线，以保留「万物皆靠抽卡」的核心。

### 1.3 战斗风格克制意味着「对策>盲目堆数值」

Melvor 的 Combat Triangle 根据自身与敌人攻击方式调整伤害和防护，给玩家切换装备/攻击风格的理由。

- [Melvor Wiki Combat Triangle](https://wiki.melvoridle.com/index.php?title=Combat_Triangle)

**本项目改造：**
- 只保留三种与修仙更相称的功法倾向：**剑势、守势、灵势**。
- 原 T001 流云剑经/T004 九霄破军诀 = 剑势；T002 玄武炼体篇 = 守势；T003 御灵同心诀 = 灵势；未获得功法时为中性。
- 项目原创克制环：**剑势克灵势 → 灵势克守势 → 守势克剑势**。优势造成×1.12最终攻击伤害、承伤×0.90；被克造成×0.89伤害、承伤×1.11。用数值小幅引导，但不允许“没抽中某张特定卡就永远无法通关”。
- 地图主敌流派：青云=剑势、灵竹=灵势、乌藤=守势、剑冢=剑势，另有一层不同风格的前哨妖卫来检验一套功法能否连过多波。

### 1.4 战斗时间与收益必须绑定

Melvor 决策常常围绕每小时稳定收益、自动战斗安全、目标敌人和副本完成率，而不只是伤害数字。原版v0.8的「一场战斗固定若干回合」导致功法与部分经济卡相对缺乏可解释的时间反馈。

- [Melvor Beginners Guide, Combat](https://wiki.melvoridle.com/index.php?title=Beginners_Guide)
- [玩家常用的模拟器README（不同敌人的收益/单位时间）](https://github.com/coolrox95/Melvor-Idle-Combat-Simulator)

**本项目改造：**战斗内部开始使用英雄和敌人的攻击间隔推进事件：初始基础约英雄2450ms、敌人2650ms；速度卡与洞府云台降低英雄间隔并提高单位时间资源产出。当前四图是面向快速验收的压缩挂机切片：**UI的单场自动战斗循环尚未精确等于模拟内的总回合毫秒数**，不应声称已经实现Melvor同等真实时间模拟或离线收益。

## 2. v0.8.2 实际落地的战斗公式

所有规则位于 \`src/v8/combat-depth.mjs\`，并由 \`engine.mjs\` 输入当世三围、功法、灵宠、永久遗物。

### 2.1 命中概率（不是照搬角色数值等级）

\`Accuracy = 96 + 2.7×攻击 + 0.25×防御\`  
\`Evasion = 110 + 2.45×防御 + 0.68×攻击 + 地图闪避修正\`

\`Accuracy ≤ Evasion\` 时：

\[
P(\mathrm{Hit})=\max(0.32,0.5\times Accuracy/Evasion)
\]

\`Accuracy > Evasion\` 时：

\[
P(\mathrm{Hit})=\min(0.93,1-0.5\times Evasion/Accuracy)
\]

*命中上下限是本项目候选平衡参数，不是Melvor官方统一常数。* 能防止高闪避使玩家完全无法造成伤害，也避免100%准确导致攻防系统没有区别。

### 2.2 主角攻击、防御和功法

- 每一次命中基础伤害浮动为最大伤害的约72–100%，再结算敌人防御、流派倍率和功法。
- **敌方回避决定有多少攻击打不中；敌方防御决定打中后造成多少伤害**，这两种损失原因分别展示。
- 主角防御参与回避计算，同时通过\`防御/(防御+230)\`生成受伤减免（上限48%）。此处为了保留现有三围结构，**与Melvor原作「Defence主要影响回避、减伤由其它来源提供」不同**。正式引入法宝/防具系统时再把抗性独立出来。
- 守势功法的减伤与角色基础减伤相加后有**总承伤减免68%硬上限**，避免多系统无限叠加免疫所有Boss。
- 灵宠主动攻击按其自身功法系数结算，不偷渡给修士主攻击。玄龟护盾在一次地下城开始时生效，跨波不刷新；雷隼独立穿甲。

### 2.3 多波守卫与Boss

| 目标 | 交战阶段 | 战斗结束判定 | 失败后 |
|---|---|---|---|
| 当前关普通小怪 | 1波 | 击败小怪，获得稳定灵石与修为 | 原地继续刷 |
| 关卡守卫 | 前哨妖卫→守关者，2波 | 2波全部击败才推进下一关 | **不退关、不领守关奖励** |
| 地图Boss | 阵前守卫①→阵前守卫②→Boss，3波 | 全部击败解锁下一张地图 | **不退关、不领Boss奖励** |

角色血量和护盾贯穿整场挑战；守卫小怪有较低血量/攻击量作为热身，Boss保留原本主题战斗属性和特殊效果。当前4图的主题机制：
- 青云：山君咆哮，每4次Boss攻击有额外爆发；
- 灵竹：阵雾回避，Boss更难命中；
- 乌藤：每2次Boss攻击有小额回复，重点比拼有效输出效率；
- 剑冢：残魂剑意带少量反震和阶段性爆发，考验持久战生存。

此处以**真实连战**替代原本只有一个血量上限的伪Boss，加入数值之外的职业克制与生存风险。

### 2.4 自动冲关不再偷窥下一场真实随机种子

原版 v0.8 调用 \`fight(save)\` 得到单一确定胜负，可能使UI误导为下一场百分之百能赢。

新版 \`combatAssessment\` 根据英雄/敌人公共统计生成**独立、确定可复现的24组随机战斗样本**；预测过程不消耗正式存档种子。
- 展示当前抽卡构筑的**样本胜率**、双方命中率、预估最危险单击、减伤及波次数。
- 自动挑战仅在胜率达到83%及英雄最大血量达到样本最大敌方一击×1.5以上时允许执行，否则继续当前关刷怪。
- **手动挑战随时允许**，所以有冒险路线也有低风险放置路线。
- 真正的战斗有独立RNG，真实结果可能偏离预估；失败只结算失败，不退关。
- 此胜率是有误差的**样本估计**，不是未来实际结果、更不是经过长期校准的概率真值。


### 2.5 普通刷怪不再只有一个目标（新增）

研究 Melvor 的怪物选择之后，为**同一关卡**加入三个可切换的小怪生态，独立配置在 \`data/v8-slice.json\` 的 \`farmTargets\`：

| 刷怪选项 | 小怪血量 | 小怪攻击 | 灵石倍率 | 修为倍率 | 对玩家的意义 |
|---|---:|---:|---:|---:|---|
| 山野小妖（均衡） | ×1.00 | ×1.00 | ×1.00 | ×1.00 | 稳定日常积累 |
| 藏金灵兽（灵石） | ×1.16 | ×1.08 | ×1.75 | ×0.60 | 更快筹集抽卡资源 |
| 聚灵幽精（修为） | ×1.08 | ×1.10 | ×0.68 | ×1.65 | 冲击下一个境界前持续积累 |

- 玩家可以在**战斗页面直接选择刷怪目标**，保持当前地图/关卡进度；切换不消耗灵石、不重新抽卡。
- 不论刷哪一种，小怪只掉落**基础资源：灵石和修为**，并且要真实击败才有收益；不会直接掉卡牌、突破丹、遗物。
- 后续可以再按地图加入各自特色的小怪词缀，但本次优先实现可切换收益目标，避免先把内容数量堆上去。

## 3. 玩家能在 v0.8 预览页观察的变化

1. 战斗页面「当前积累收益」区域新增：**守卫胜率（24次模拟）／功法流派与克制／双方命中率／承伤减免与最强单击／多波数与预计出手次数**。
2. 对撞动画和血条可显示多波交战，出现闪避文字、灵宠攻击、Boss回复或反震。
3. 在功法页装备剑势、守势或灵势功法，返回战斗页观察Boss匹配关系和胜率，找到对策再继续刷怪或尝试守关。
4. 继续强化角色的来源**仍然只有战斗资源与七个卡包**；改造没有引入直接花灵石买战力等级或掉装备强化方式。
5. 四图/炼气→筑基规则、永久天命测试池、全部旧v0.8存档Schema不改，留在原本的独立预览页即可验收。

## 4. 版本边界和下一轮值得做的事

- **还未实现**：Melvor完整Auto Eat/食物系统、敌人异常状态净化/抗性免疫、24张地图所有特殊攻击、离线真实回合结算，以及真实时钟/掉落效率完全同步的24小时持久挂机。它们是下一轮功能而不是本次已完成。
- **已保留的项目原则**：修炼境界而非Lv数字等级、当前关小怪长期积累、守卫Boss独立难度墙、功法/洞府/宠物/突破材料从抽卡产出、主动轮回保留永久遗物。
- **需要真人试玩验证**：24次采样的胜率是否对玩家足够准确、Boss多波血条是否易读、守势功法是否过于万能、目前自动间隔是否需要进一步与真实总战斗时长挂钩。
- **后续建议**：每地图增加普通怪的两类可选刷取目标（一个高灵石、一个高修为），仍不掉成长卡；强化「长期刷怪也是有选择」的乐趣。再添加可公开预测的Boss特技冷却倒计时、阶段性单抽保底与安全放置阈值。

## 5. 工程验证

- \`npm run check:v8\` — Schema、UI、玩法事务及新增战斗子模块的测试。
- \`npm run simulate:v8\` — 小规模原引擎三路线真实对局验证。
- \`npm run simulate:v8:full\` — 100种子×3路线总计300轮完整推进，观察通关率/每世战斗数/抽数/失败数/是否不能刷当前关小怪。
- CI 执行对应工作流：\`v8-slice.yml\` 和 \`v8-combat-balance.yml\`。
- 当前预览仍为 \`preview-v0.8.html\`，不更新 v0.7.1 试玩入口。

> **判断标准：**不是所有人无脑挂机都能过Boss，而是守关难度可以被读懂、当前关小怪始终能积累、装备有实际克制、突破更有价值、不存在无法补救的掉率死锁。
