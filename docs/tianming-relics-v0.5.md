# 天命遗物箱与鸿蒙异宝 v0.5

> **设计提案 / 尚未实装。** 本版替换 v0.4 中“所有遗物同等可毕业”的终局体验。  
> 统一配置：[codex.v0.5.json](../data/codex/codex.v0.5.json) · [遗物数值表](../data/codex/relics.v0.5.csv) · [整体 GDD](GDD-v0.5.md)

## 1. 参考点与差异化

参考 [Obelisk Miner Wiki: Chests](https://obeliskminer.fandom.com/wiki/Chests) 描述的普通、Mythic、Divine 遗物箱、永久被动、叠层成长、极稀有顶级收藏，以及部分遗物达到上限后不再进入池子的规则。社区资料给出的 Divine 基础概率约 **1/25,000 (0.004%)**，**是参考游戏数据，不是本项目采用的概率**。

本项目候选使用：
- **常规遗物箱**：抽 1 件五档永久遗物（黄/玄/地/天/仙），让普通玩家有持续收益。
- **鸿蒙异宝追加判定**：**独立 0.01%（1/10,000）**，成功则同时额外获得 1 件鸿蒙异宝；总共4件，每件只能获得一次。
- **鸿蒙永远没有保底、软保底、隐藏递增赔率**。也不会用看广告、付费礼包来提升其单箱概率。
- 若鸿蒙已全部集齐，鸿蒙奖池结束，抽箱按钮明确显示“鸿蒙全收集”。
- **鸿蒙是第六种特殊收藏标签**，不属于常规五档概率总和，也不会因为仙阶保底触发就一并提高概率。

### 1.1 公开的数学预期

设每箱独立触发鸿蒙的概率 p = 0.0001：

| 累计开启箱数 | 至少出现一次鸿蒙的概率（近似） |
|---:|---:|
| 100 | 1.0% |
| 1,000 | 9.5% |
| 5,000 | 39.3% |
| 10,000 | 63.2% |
| 20,000 | 86.5% |

计算：P(至少一次) = 1 - (1 - 0.0001)^n。**一万箱不是保底**；若只有一世一箱，超稀有绝大多数玩家永远看不到。因此长期必须靠更深层轮回提升普通开箱数量，而不是要求玩家增加广告观看次数。

- 未持有任何鸿蒙时，四个候选异宝在触发鸿蒙后等权随机选取，所以**每个指定异宝单箱基础概率 0.0025%（1/40,000）**。
- 已拥有某件后从鸿蒙奖池移除；**总体鸿蒙出现率仍然为 0.01%**，只对尚未拥有的鸿蒙物品内部重新均匀分配。
- 若全部已拥有，就不再触发鸿蒙独立判定；公告中的可掉落鸿蒙列表显示已毕业。

## 2. 基础常规箱与鸿蒙判定的区别

| 维度 | 五档常规遗物 | 鸿蒙异宝 |
|---|---|---|
| 是否每箱都有 | 有（直到常规30种完全毕业） | 仅0.01%独立额外掉落 |
| 数量 | 30件，各自可重复叠层 | 4件，各1份 |
| 品质池 | 黄/玄/地/天/仙，合计100% | 独立“鸿蒙”判定，不分摊常规概率 |
| 天/仙保底 | 原v0.4候选20箱天阶+ / 60箱仙阶 | **完全不适用** |
| 达上限处理 | 对应常规物品从常规池退池 | 已拥有的鸿蒙在成功时不再可选 |
| 溢出处理 | 全部常规满级后转图鉴共鸣（见下） | 不会产重复 |
| 是否装备 | 否，所有已拥有自动生效 | 否，所有已拥有自动生效 |
| 轮回重置 | 否 | 否 |
| 是否作为通关要求 | 否 | **绝对不能** |

普通箱价格暂沿用**40因果单抽、400因果十连**，共享同一常规保底计数；十连相当于连续执行10次单抽，包含10次独立鸿蒙判定。常规满图鉴后仍然可开箱，但收益改成共鸣进度，价格不变、鸿蒙概率不变。

## 3. 四件超稀有鸿蒙异宝（各上限1）

| ID | 名称 | 全局永久效果 | 为什么“变态”且值得追 |
|---|---|---|---|
| **TM-031** | **鸿蒙开天斧** | 主角普通攻击结算最终伤害 **×2.5** | 推图速刷、肉身修炼流质变；只放大主角而不包括灵宠 |
| **TM-032** | **万灵始祖印** | 出战灵宠实际造成的最终伤害 **×4.0** | 御兽流进入全新效率等级；无灵宠时不生效 |
| **TM-033** | **无尽洞天珠** | 已建造洞府提供的**资源收益加成部分 ×3.0** | 长局资源循环爆发；无洞府/无正向收益时不起效 |
| **TM-034** | **三千大道书** | 已装配功法产生的正向数值效果 **×2.5** | 功法路线质变；不放大装备负面效果或已被其它遗物加成的残余数值 |

### 3.1 明确计算位置，避免互乘错误

**开天斧**作用于主角最终伤害，含其功法加成后的主角伤害；不作用于灵宠、反伤、环境伤害。每次主角出手最多乘一次。

**始祖印**只作用于宠物本身造成的输出，不作用于宠物护盾、治疗、给玩家的被动属性，也不增加宠物经验获得率。

**洞天珠**只把“已建造洞府产生的**增量收益百分比**”扩大，其他遗物的资源收益不乘3。例如洞府本来+20%灵石，拿到珠后变为+60%这一个加成；不是最终所有灵石×3。如果没有建洞府，收益为0，避免天命遗物取代洞府玩法。

**大道书**作用于各已装配功法定义的**允许放大的正向数值**，不是所有战斗最终倍率，也不能再乘鸿蒙开天斧。带有未注册机制的功法不得被倍率器强行套入。

两件鸿蒙如果同时拥有，允许分别增强主角与功法/宠物/洞府的对应部分；因此**多件同时拥有有明显组合收益**。但常规玩家不能以此为平衡基准，Boss的可通关门槛只能按“没有鸿蒙”来定。

### 3.2 特殊得到时的演出

- 单件获得是全局小里程碑：鸿蒙专属动画、一次性全图鉴高亮、文字记录、永久标识。
- 开启 10 箱若成功获得鸿蒙，抽卡结果必须突出展示“额外获得”，而非隐藏在普通卡牌中。
- 公告必须真实：只有玩家实际获得才显示，不能虚构“某玩家刚刚抽出”的假走马灯。
- 允许关闭动画和合并批量结果，不用稀有演出强制拖长操作。

## 4. 常规毕业后的超长线出口：图鉴共鸣余响

v0.4 在30件常规遗物全部封顶时禁止开箱，会导致鸿蒙概率无法继续尝试。本版必须补上终局路径。

### 4.1 状态

当30种常规遗物全部到上限，天命箱仍保持 40 因果/箱：

1. 常规遗物结算改为**共鸣经验 +1**（不再抽已经毕业的普通遗物）；
2. 开箱仍独立判定一次鸿蒙，概率恒定0.01%；
3. 共鸣经验自动累积，不是新可交易货币；没有单独购买、抽卡或兑换入口；
4. 每 **25点共鸣经验**升1共鸣等级，最高 **100级**；
5. 共鸣等级每级增加**主角基础攻击、气血、防御各0.1%**，满级总+10%（与其它基础属性百分比同组加算）；
6. 超过共鸣100级后不再提升属性；**有未拥有的鸿蒙异宝时**仍可自愿开箱追求鸿蒙，UI必须明确提示“本次仅有0.01%鸿蒙追加机会，无其它数值收益”。**若四件鸿蒙全部获得，此时禁止继续扣费开箱。**

**共鸣不是第四种资源**：用户无需在商业循环中管理它，等同于永久图鉴自动进度/成就计数。仅用于防止常规收集毕业后鸿蒙箱功能被强行关闭。

### 4.2 奖池判定伪代码

~~~ts
openChestOnce(meta, rng) {
  assert(meta.fate >= 40);
  assert(hasOrdinaryAvailable(meta) || resonanceLevel(meta) < 100 || hasUnownedUltra(meta));
  const pool = ordinaryRelics.filter(r => meta.copies[r.id] < r.maxStacks);
  const ordinary = pool.length
    ? drawWithTierWeightsAndPity(pool, rng, meta.ordinaryPity)
    : {kind: 'resonance', amount: 1};

  const unownedUltra = ultraRelics.filter(r => !meta.copies[r.id]);
  const jackpot = unownedUltra.length && rng.float() < 0.0001
    ? uniformPick(unownedUltra, rng)
    : null;

  // All effects commit together. A jackpot is an extra reward,
  // and must never replace or diminish the ordinary reward.
  commitAtomic(meta, {costFate: 40, ordinary, jackpot});
}
~~~

若全部常规已毕业，普通天/仙保底进度应被冻结或标记为“常规已毕业”，不能继续显示下一次仙阶必出却只发共鸣。开箱有效性条件为：**仍有常规可抽，或共鸣还未满级，或仍有未拥有的鸿蒙异宝**；三者同时不成立时必须拒绝抽箱。

## 5. 获取节奏与保底诚实性

### 常规遗物

- 五档正常保持可控的长线毕业；某档满级后从五档有效概率分布中移除并重新归一化。
- 天阶/仙阶保底只保证常规阶位，有可抽奖品才生效。
- 玩家即使当世没有新稀有卡，也至少能通过修炼与卡牌升级获取成长；轮回后的常规遗物逐步提高速度。

### 鸿蒙掉落

- **无保底、无软保底、无概率随抽数提升**，每次固定0.01%，其它常规稀有掉落不会降低/提高它。
- 该概率对新玩家与完成常规图鉴的老玩家完全一样。
- 不能把鸿蒙限定为通过某个高难层以后才能出；关卡只渐进开放鸿蒙图鉴详情与收藏提示，**从首次天命开箱就存在概率**。
- 广告、内购、节日活动都不能改变鸿蒙基础概率，除非未来作为单独版本改动对全体用户明示和重新审批。

## 6. 全局效果注册及硬上限

- 普通遗物同 \`effectKey\` 的层数值**相加**；硬帽至少有破甲60%、伤害减免60%、强化折扣60%、宠物首回合护盾35%主角最大气血。
- 鸿蒙通过独立、按类别各不超过一次的 \`ultraMultiplier\` 注册，明确“放大什么，不放大什么”；系统默认拒绝未知的效果 Key。
- 鸿蒙倍率不可被别的卡再次以“触发另一个鸿蒙”的方式循环调用。
- 局外遗物绝不增加轮回**因果倍率**、提升自身开箱速度、产生更多鸿蒙箱或者在广告结束时触发额外几次概率判定。
- 任意使用者更换功法/卸下洞府/切换灵宠，鸿蒙增益实时响应当前状态，且不会改写永久拥有信息。

## 7. 图鉴字段与模拟指标

每件遗物展示 ID、系统、基础稀有度、获取方式、效果、每层/上限、是否可重复、对应功能、实际属性贡献与收藏状态；鸿蒙遗物多展示：

- **每箱概率（整体奖池）0.01%**，以及尚未收集的每件异宝在当前未收齐状态下的条件概率；
- 记录累计箱数/至今未中次数，但不能暗示下一抽概率增加；
- 击破新高难 Boss 之前展示当前遗物对战斗的贡献值；
- 未拿到时允许从图鉴里预览“如果拿到，将使本局角色/灵宠/洞府/功法产生何种实际加成”。

长期模拟必须记录：
- 1,000 / 5,000 / 10,000 / 20,000 箱至少一件鸿蒙的频率；
- 四件全部收集的实际时间分布，不能拿“单件均值1万箱”当做全收藏预估；
- 普通30件毕业的箱数分布、共鸣100级耗费、因果箱供应情况；
- 0鸿蒙账号完成全部普通主线/险境的比例；
- 获得某件鸿蒙后对角色输出、宠物贡献、洞府回本和平均单局时长的影响；
- 极端欧皇一口气出两件鸿蒙的账号是否破坏非鸿蒙内容经济。

## 8. 反挫败与商业化边界

**罕见不代表让99%的玩家没得玩。** 角色修炼、境界突破、功法、灵宠、洞府与常规遗物都要能够带来可见成长。鸿蒙是体验的倍率上限，而不是玩家日常爽感的唯一来源。

所有稀有度数值在抽卡界面公开；显示概率与实际算法一致，不伪造保底，不暗示任何抽数可以“必出鸿蒙”；玩家跳过稀有动画、批量开启时都获得严格一致的结果。

**来源与范围**：参考 Obelisk Miner 的稀有追求感，本游戏的异宝效果、数值、名称均为原创候选；v0.4 遗物数据作为历史档案保留。
