## 必须亲手验证的六个场景

1. **开局即抽战力**：新存档有65灵石，进入战力秘藏单抽；第一抽保证获得「破军剑诀」，攻击上升16；页面完全没有淬锋/锻体/护脉三个直接升级按钮。
2. **自动推图和卡关自动退层**：点自动推图，击败敌人继续推进；打不过时自动刷刚刚通关的前一层获得灵石，而不是停在失败画面；再次抽卡提升战力后会尝试返回原关。
3. **第5层聚财**：聚财机缘解锁后抽取卡牌，灵石掉落倍率和/或战斗结算间隔发生变化，效果可从状态栏与背包核对。
4. **第10层修炼**：修为造化卡包开放；原本Lv.10有等级封顶，抽一张修为卡后提高等级上限，同时有机会提升修为收益倍率或属性，使自然修炼继续成长。
5. **第16层丹道、第20层境界锁**：抽丹道宝匣，最迟第8抽获得「筑基丹」；通关第20层后不管当前战力多少都无法直接推21层，必须达到Lv.12且背包有筑基丹；点击突破会消耗一枚丹药、变为筑基，并继续冲关。
6. **30层终点与存档**：30层后不应进入未开发的新地图，扫荡仍可持续，刷新页保留数据；备份重开不影响旧M0和v0.1进度。

## 自动化验证与范围说明

运行 \`npm run check\` 将执行关卡数据检查、抽卡/成长/突破单元测试、5种随机种子的推图模拟与Pages静态检查。自动测试通过只证明逻辑闭环，不代表正式游戏的难度、关卡节奏、卡包经济已经最终平衡。浏览器渲染与手机操作仍需人工验收。

请优先反馈三点：**是否明显感受到抽卡前后的实力差异；卡关刷旧层再抽卡是否形成期待；逐步解锁是否给到足够的新鲜感。** 这三项决定要不要进入更大量内容的开发。
