## 你能完整玩到的内容

- **青云山麓 → 灵竹溪谷 → 乌藤鬼林 → 雾隐剑冢**：四张可玩地图，每张8个关卡点（前7段守卫＋最终Boss），守卫不倒不解锁下一关，最终Boss击败后开启下一图。
- **当前关刷怪**：小怪独立于守卫；失败后继续刷同一关的小怪，永远不会强制倒退。可连续自动刷小怪，也可开启「自动冲关」，系统预测能打过守卫时才自动尝试。手动挑战任何时候都可用。
- **无数字等级的修炼**：炼气初期／中期／后期／圆满；通关第四图Boss、修为+悟道+筑基丹达标后，进入筑基初期。修为门槛按地图规划JSON的指数公式计算。
- **修为抽卡必得悟道**：无论抽到增益卡还是直接悟道卡，每次修为造化抽取都额外保证至少1点悟道。**每一次抽卡都有确定性境界进度。**
- **7类真实卡包**：战力、聚财、修为、功法、洞府、御兽、丹道。首张战力保底基础攻击；丹道8抽内筑基丹保底；支持单抽和十连。随着地图提升，抽卡花费也按候选指数倍率增加。
- **功法与灵宠**：功法一次只能主修一门，支持剑气、减伤、御兽协同、爆发；灵宠一次出战一只，支持独立输出、护主、破甲与修为协助。抽到的卡在系统内免费装配；重复抽取增加本世加成。
- **洞府经营**：建筑抽到立即生效，包括普通小怪灵石、修为、交锋速度和宠物伤害四类实用效果。
- **轮回与天命测试池**：第四图通关后自愿轮回，因果跨世保留。每40因果可开一个测试天命遗物箱：10种常规遗物叠加，四种鸿蒙为**0.01%独立追加机会、无保底**。四种鸿蒙在战斗/宠物/洞府/功法使用专项效果，而不是虚假的图鉴文字。正式30件常规遗物池仍需后续整合。

## 按照实际玩家顺序验收

1. 新档初始110灵石；先在抽卡页抽战力秘藏，返回地图可看到攻击变化。点击「自动刷本关小怪」，观察双方血条、灵石和修为收入。
2. 点击「挑战守卫」；战败后地图位置保持不变，小怪仍可反复刷。当前小怪必须是你能稳定击败的对象，保障不会死锁。
3. 击败青云山麓Boss解锁灵竹溪谷；前往修炼界面，完成炼气初期→中期的突破。**不允许在没有地图Boss许可时提前突破。**
4. 尝试功法秘卷、御兽灵契或洞府营造；比对怪物受伤、宠物独立攻击和每场灵石/修为收入的变化。
5. 继续击败第二图、第三图Boss并分别达到炼气后期、圆满，观察修为/抽卡成本逐渐提高。
6. 在第四图打败雾隐剑冢Boss；通关后**仍允许刷该关小怪**来积累筑基丹和悟道。凑齐足额修为、悟道以及筑基丹后，从修炼页面主动突破「筑基初期」。
7. 前往轮回天命页面，确认清楚本世将会重置，主动轮回获得55～65因果；开一次40因果的常规测试遗物箱，重玩第一图验证永久属性和收益。
8. 刷新浏览器检查进度保留；通过设置页导出当前存档。重开前会将预览版旧档备份，原 v0.7.1/M0/v0.1 记录不受影响。

## 开发边界与已知限制

- **目前只有前4/24张地图可玩**；后20张已写入地图图鉴和稳定JSON，但敌人技能、深入境界、地区资源并未标记为完成。
- **只有前5/20个境界状态能够在切片中达到**：炼气四阶段＋筑基初期；其余15阶段作为后续地区扩展的数据模型。
- **解锁节点故意未冻结**：为了方便用户体验，七个卡包本切片全部初始可用；后续定版按账号首通里程碑渐进解锁，不必重写系统。
- **战斗预测目前基于确定性示例战斗**，用于安全地自动推关；完整版本要加入可统计风险区间与挑战冷却。
- **无离线收益**：浏览器后台会暂停自动战斗，不因关掉网页凭空发放资源。
- **本版本常规天命只收录10件测试遗物**，不是正式30件卡池；鸿蒙万分之一属于概率事件，短期体验绝大多数玩家不会抽到。
- 四图模拟只是验证经济不死锁，不等于已经验证最终24图的指数成长时长，也不代表所有玩家行为最优。
- 当前页为 GitHub Pages 本地单机，换设备不会自动同步，请使用导出存档功能备份。
