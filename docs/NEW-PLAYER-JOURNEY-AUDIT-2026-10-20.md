# 《抽卡修仙传》新手全流程体验审计 · 2026-10-20

**结论：全程可打通，但首世成长路径严重偏离“抽卡修仙”的设计承诺。应先修正境界/地图节奏、首次操作引导和抽卡系统性价比，再扩地图或继续美术打磨。**

> 审计基于主分支 `ed3375e`（此报告及诊断脚本仅存于 `audit/novice-first-life-journey` 分支，未修改主游戏）。没有真人访谈，不应把引擎驱动的模拟误称为三名真人实际试玩；也不意味着全部长尾问题都已经发现。

## 方法

1. 以新号 `createSave(seed)` 开局，完全通过现行游戏的 `dispatch`、`fight`、`combatAssessment`、`nextStep` 模拟实际操作。按 **页面动态修行建议** 决定下一步：建议守关则守关；缺功法/灵宠/装备则抽指定卡包；卡关则对比已拥有功法灵宠构筑、强化战力或打小怪攒灵石；Boss 全通后根据建议补悟道、筑基丹与修为，突破至筑基、轮回、开第一箱天命遗物。
2. 固定种子 `20261020`、`23`、`71`。不改抽卡权重、战斗数据和地图门槛，不给测试玩家免费资源；所有收益、耗损和库存由正式引擎计算。
3. 时长模型：使用真实模拟战斗耗时，另为每次普通操作估算2–6秒。这是**估算累计时间**，不等于真人实测；不包括找按钮、犹豫、阅读、反复点击跳过动画、现实设备切后台所增加的负担。
4. 两个 Chromium 视图经 iframe 测试了初始页面、导航到抽卡、实际点击「战力单抽」、跳过动画和收下机缘；取得实时 DOM/坐标测量。Chromium 下的内层 iframe 有自己的视口尺寸，不能把这些尺寸误称真机物理屏幕。

## 逐阶段复盘

### 0. 首次进入——P0

- 首屏没有明确的强制/可跳过三步教学；呈现十个装备槽、四个法器槽、功法灵宠、构筑推演、多个战斗按钮，让首次进入的玩家分不清第一步该做什么。
- 首页建议“胜率96%，挑战守卫”而非引导首次抽卡，与游戏核心定位相冲突。
- 九个卡包同时展示、前七个开放；新玩家不容易判断先抽战力、功法、灵宠、修为还是经营收益。
- 实际 Chromium 首抽流程可走通，按钮、动画跳过和收下均能执行。脚本测试的嵌套视口中，战斗操作位于首屏下方（例如约500×643内层视口，自动刷怪按钮的DOM纵坐标约1590px；844×258内层视口约383px）。这不是所有真实设备的精确坐标，但表明核心操作被角色与装备信息挤到后面，有发现门槛。
- 顶栏仍有“返回旧版”入口，首次接触的新用户可能误入独立存档的旧Demo。

### 1. 第一图——P0

- 实际可以在炼气初期连续打守卫、击败第一图Boss，且很少需要认真理解招式克制。
- 第一张战力卡的直接属性提升真实存在，部分稀有功法/灵宠效果也真实生效，但**为什么需要这些牌**并未由战斗目标引导玩家理解。
- 目前的“战前推演”会在所有已持有配置里计算胜率，新手不理解不同属性之间的因果链；建议加入具体说明，例如“玄龟护盾抵消当前Boss首轮爆发”，而不仅是百分比。

### 2. 第二、三图——P0

- **没有境界门槛**：进入第二、三、四图不要求炼气达到中/后/圆满。模拟中全部四个Boss都在炼气初期击败。
- 成长变成“攒钱→抽战力→继续挑战”，聚财、洞府和刷怪重点的长期经济价值没有自然出现。四图主线几乎完全绕开其中两类系统。
- 10槽装备抽到后可自动穿第一件，但已有槽位的新装备不会自动替换，缺少显著的“更优替换”提示；新手可能误以为抽到高级装备就已经自动提升属性。
- 死亡掉装50%虽有文本告知，但守卫按钮旁缺少直观的风险说明；一个低概率死亡可能丢失高阶装备，新手的挫败感较强。

### 3. 第四图与最后Boss——P0

- 三次均能靠集中购买战力卡推进。越往后，反复刷怪和抽战力的操作比重越大，而策略组合并非每张地图的必须选择。
- 最终Boss胜利后竟需额外约55次操作处理修为、悟道、筑基丹才完成筑基，出现明显“主线已过却还要补手续”的断层。
- 很多资源应该在第四图探索时提前提示并累积，而非最终Boss后才让玩家开始关心。
- 抽卡当前通常需要点击抽取、等待/跳过演出、点击「收下机缘」；每轮成百次抽卡意味着额外大量重复点击，后期需要连续抽取/重复抽取的操作减负选项。

### 4. 首次轮回——P0/P1

- 在第四图Boss击败后，即使没有筑基也能轮回（55因果），筑基后轮回则得65因果；现有UI按钮放开且确认文案没有突出10因果差距。提前轮回可能导致无法同时买40因果天命箱和25因果自动服药解锁。
- 常规天命箱确实保证一件永久遗物，但随机得到的可能是只提升尚未拥有灵宠的加成；第二世刚开局时可能**没有立即可感知的增强**。
- 玩家丧失本世装备、卡牌和地图进度，第二世又面临同一开荒循环，缺乏首次轮回专属爽点。

## 可执行整改顺序

### P0-1 首次3分钟教学与操作排布
- 首次登录提供可跳过的三步指引：**抽第一张保证有用的战力卡 → 自动刷小怪一次 → 首次挑战守卫**，并用动画指向对应控件。
- 新号第一阶段只凸显当前操作；暂时收起高级装备、法器、推演和自动冲关，使主要战斗按钮保持在战斗页面首屏可见的位置。
- 清楚区分「挂机刷资源」与「挑战守卫推进关卡」。隐藏旧版链接到设置或开发者信息区。

### P0-2 修炼/地图强绑定、消除后置补课
- 第一图Boss后引导突破炼气中期，再放行第二图推进；第二图→后期；第三图→圆满；第四图Boss→筑基。必须明确处理避免地图与境界互相锁死，推荐地图转换前在过渡站提供当前图小怪刷取。
- 每个地图终章给出突破资格、所差修为/悟道进度和对应卡包的一键跳转。下一步指引应优先处理适时的突破，而不是只看守卫胜率。
- 最终Boss之前就展示筑基丹8抽保底、准备阶段、已有库存，避免Boss之后突然堆50次操作。

### P0-3 抽卡策略多样化
- 不直接粗暴提高聚财和洞府的属性：先调整关卡资源曲线、早期成长门槛、投资回报与目标推荐，让至少战斗流、修炼流、经济流均有真实通过路径。
- 设计局部动态目标：不只是“战力不足”，而是提示“当前敌人闪避高→命中/宠物技能”“气血薄→护盾/防御”“接下来准备筑基→悟道/丹药”。
- 验收：对多个种子重复模拟，聚财/洞府不再长期0抽，战力卡不再稳定超过80%总购买；这些只是调优目标，需防止为了满足配比强迫玩家消费无效卡。

### P0-4 轮回价值与成本透明
- 若尚未筑基，轮回确认框明确显示“现在55因果；完成筑基后65因果（多10）”。
- 第一次天命奖励至少确保有一种**立即可感知**的跨世提升；可让玩家首次从数个等值方向中选择，而不必改变后续常规概率池。
- 展示当前世与下世首图预期效率对比；第一轮回给一次新解锁或流程简化体验。

### P1 操作减负
- 在已有相同类型已装备的物品池中显示“可替换/属性变化”，提供合理的一键推荐但保留确认权。
- 抽卡按`首次稀有/重复普通`可配置演出：首次有完整仪式，批量重复支持快速收下；不能改变发奖事务。
- 合并重复信息卡片，手游横屏右侧始终看到敌方与行动按钮，角色装备放二级面板。
- 修正无效旧文案、过多尚未解锁的大地图/法器控件，同时把金币、气血与实际敌人类型对齐。

### P2 验证真正的新手可理解性
- 至少3–5名未读GDD的新玩家，记录首次点击、30秒内首抽、2分钟内解释刷怪/守卫区别、10分钟内是否突破、第一次轮回是否理解所得与损失。
- 分析不只看通过率，还要看放弃率、首次卡关动作、重复无效点击和手机操作反馈。
